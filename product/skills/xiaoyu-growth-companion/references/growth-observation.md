# 成长观察协议 v1

成长观察描述的是“小宇记里已有证据呈现出的变化”，不是对孩子真实能力的完整测量，更不是医学或教育评定。

## 证据单位

一条有效证据至少有：`日期`、`孩子原话或具体行为`、`场景`、`记录来源`。记录来源只能是孩子会话、家长手动观察或家长确认的活动结果。

同一次会话中重复出现的内容通常只算一个证据。模型总结不能反过来作为新证据。

## 内部显示门槛

以下门槛只控制何时向家长显示某个词，不代表年龄常模：

| 表述 | 最低证据条件 |
|---|---|
| 暂时没有足够记录 | 少于2条相互独立证据，或时间跨度少于7天 |
| 刚刚出现 | 至少2条证据，跨越至少7天 |
| 正在练习 | 至少3条证据，来自至少2种场景，跨越至少14天 |
| 逐渐稳定 | 至少4条证据，来自至少3次会话，跨越至少21天 |
| 经常主动使用 | 至少5条证据，来自至少4次会话，跨越至少28天，并有家长确认 |

家长纠正、证据冲突或上下文不清时，降低结论确定度而不是强行归类。长时间没有新记录只标记“近期记录不足”，不能自动降级为退步。

## 允许的观察维度

- 兴趣主题和问题方式的变化。
- 表达长度、叙事顺序、理由和主动提问的可见变化。
- 在真实活动中尝试的策略、坚持、求助和调整。
- 与家人朋友相关的感受、协商和换位表达。
- 运动、自理、艺术与科学探索中的具体行为。

这些维度与3-6岁五领域可对应，但前端不需要显示研究术语或五项雷达评分。

## 输出格式

```json
{
  "label": "正在练习",
  "claim": "最近开始用先后顺序讲幼儿园的小事。",
  "evidenceIds": ["moment-001", "moment-014", "moment-019"],
  "confidence": "medium",
  "parentConfirmed": false,
  "alternativeExplanation": "也可能只是最近更愿意谈这个主题。",
  "nextAction": "晚饭后请孩子挑一件小事，从最先发生的开始说。",
  "sourceIds": ["CN-MOE-ELDG-3-6-2012"]
}
```

结论必须能点回原始证据，并允许家长隐藏、纠正和确认。

## 禁止

- 不输出数字分数、百分位、排名、预测升学或与同龄人比较。
- 不使用“落后、异常、天才、内向、注意力差”等稳定标签。
- 不把家长输入、模型推测或单次表现写成客观事实。
- 不声称来源能够验证产品自己的阶段门槛；门槛需要真实家庭纵向试点校准。
