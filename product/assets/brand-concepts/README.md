# 小宇记 Logo 探索：A 方向

> 2026-08-29：A1 已选为小宇记当前主视觉方向，并以 `../xiaoyu-planet.png` 作为产品内稳定引用文件。其余版本保留为探索记录，不进入当前界面。

## 核心概念

“小星球小宇”：把“记录孩子自己的小宇宙”变成一个有生命感的小星球伙伴。

共同约束：

- 正方形 App 图标构图，不含文字。
- 极简、可爱、拟人化，使用圆润厚重的形状。
- 每张只使用两种角色语义色和一种纯色背景。
- 角色由 4-7 个主要形状组成，保留大面积留白。
- 奇数方案从左下角进入，偶数方案从右下角进入。
- 轨道环同时表达“陪伴”“成长轨迹”和“持续记录”。

## 生成记录

- 生成方式：OpenAI 内置图像生成，GPT Image 2。
- 生成单位：六张独立图片，不是拼接图或联系表。
- 约束传递：全部直接写入主提示词。
- 通用约束文本：`Exactly three semantic colors total. No text, letters, numbers, gradients, shadows, textures, scenery, stars, dots, sparkles, extra marks, extra limbs, or accessories. Keep 4-7 major shapes, broad negative space, and a clean modern app-icon silhouette.`
- 当前文件为 1254 x 1254 PNG 位图概念稿；尚未转为 SVG，也未替换产品现有品牌资产。
