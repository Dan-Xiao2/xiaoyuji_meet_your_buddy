# 斑马真实网页测试

2026-10-05。用户授权开启本地图片生成，并追加最多6次虚构图片测试。本批实际6次，没有家庭录音或聊天数据。沿用阿里云 `qwen-image-2.0`，不换账号；费用待账单核对。

## 方法与结果

独立模拟家庭通过网页表单提交，真实调用文字路由和图片接口；禁用录音、播音及无关Tutor调用。等待页面图片解码可见后计时，同时保存截图。原始记录：`screenshots/zebra-live-2026-10-05/results.json`。

| 请求 | 页面可见耗时 | 目视结果 |
|---|---:|---|
| 画斑马 | 5.59秒 | 出现斑马，背景基本干净 |
| 黑条纹变蓝 | 6.20秒 | 蓝色变化可见，但背景杂纹明显增加，出现额外色彩 |
| 增加红气球 | 6.10秒 | 气球出现，整张画杂纹严重 |
| 删除气球 | 6.03秒 | 失败：文字路由把删除错误改写成上一轮新增要求 |
| 再测删除（从第3张开始） | 6.89秒 | 失败：气球仍在，路由输出省略删除动作 |
| 蓝条纹变黑 | 5.74秒 | 仅部分变黑，仍有蓝色，杂纹保留 |

6次接口均返回图片，390px和1440px白板均可显示；这不等于6次语义成功，也不代表儿童语音端到端速度。

## 修复与限制

- 已修复已有图片edit指令的传递：采用当前用户原话，不采用路由模型改写，以免把删除变新增；模型仍负责分流。新增回归测试覆盖错误改写，17项定向测试通过。
- 第二段付费测试在旧服务退出前已执行完，不能冒充为修复后的真实模型验证。修复已在随后重启的服务生效；剩余额度为0，未继续付费重试。
- 连续编辑纹理劣化仍未解决。当前样本不能区分图像模型、输入压缩或风格提示各自影响，需要后续控制变量实验；不声称改提示词即可解决。
- 本机开关保留开启，示例配置仍默认关闭。成人可自行尝试新图；目前不建议依赖连续编辑结果或无人陪同儿童使用。

脚本 `scripts/benchmark-zebra-browser.mjs` 必须显式付费参数；已有账本禁止重跑，唯一追加分支只允许第4次后执行余下2次。脚本不会自动追加第7次。
