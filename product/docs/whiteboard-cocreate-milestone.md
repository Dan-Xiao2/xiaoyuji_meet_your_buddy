# 白板共创：第一个工程里程碑

更新：2026-09-08。用户已同意先让同一幅画持续修改，再扩大知识讲解范围。

## 当前交付，不等于最终目标

本轮完成对象画布底座并接入现有对话入口，随后接通 Qwen 受约束操作规划。明确简单指令本地执行；更自然的绘画描述走一次 `/api/whiteboard/plan` 请求。支持范围仍是有限对象与属性，不是通用插画生成；不以固定样例的测试通过宣称任意说法成功率达到90%。

| Before | After | 为什么 |
|---|---|---|
| 只有去重后的 subjects | 每个对象有稳定 ID 和独立属性 | 可以区别两座房子 |
| 每次替换完整 SVG | 按 ID 保留节点，更新相关属性 | 不改变未被修改的对象 |
| 只有一种预设布局 | 有边界的空位放置、左右移位与占位交换 | 防止对象越界、重叠 |
| 不支持时清空 | 澄清或说明限制，保留原图 | 孩子不用从头来过 |
| 没有关系和撤销 | 小路引用两座房子，删除关联清理，最近12步可撤销 | 编辑不是互不关联的图片 |
| 所有画面依赖音频开始 | 单步立即显示，多步骤按句展开 | 单步不会因为TTS阻塞而空白，多步后续内容不抢跑 |
| 房子动画、小路立即跳终点 | 房子与小路共用逐帧位置 | 保持连接关系 |
| 每句说完才请求下一句 | 正在说话时只预备下一句 | 降低句间等待，打断即取消 |

## 五段验收分镜

1. **从空白开始**：进入对话不显示图案 → “画两座房子” → 画纸出现两个独立房子；左下角语音入口不被遮挡。
2. **说清楚改哪个**：“把屋顶涂成蓝色” → 原图不动，小宇问哪一个 → “右边的” → 仅右边屋顶变化。
3. **对象仍是同一个**：“把左边房子变小一点” → 左房子缩小 → “把最大的房子放到左边” → 大房子与占位对象交换位置，颜色与身份不变。
4. **图形之间有关系**：“中间加一条小路” → 连接两个门口 → 删除一座房子时小路同步移除 → “撤销”后一起恢复。
5. **失败不会破坏成果**：“画一只恐龙” → 保留原图并说明暂时不能准确画 → 可继续修改或撤销；导出恢复后对象与历史仍在。

前三段和后两段已覆盖自动浏览器回归，家长/孩子是否理解仍需要后续真实测试。

## 数据与模块

- `drawingScene.js`：v2纯数据协议、对象校验、原子操作、旧数据迁移。一个操作批次全部有效才应用；旧revision计划拒绝执行。
- `illustrationPlan.js`：简单中文指令本地执行；未解析的明确绘画描述标记 `needsPlanner`。`server/drawingPlanner.mjs` 用当前对象和最多4条短上下文补充语言理解，输出同一操作协议，不输出HTML、SVG或可执行代码。
- `src/app.js` / `llmClient.js`：模型规划期间保留原图，单次请求完成说画回应，不触发普通对话的quick/full双请求；取消传到服务端，迟到结果不得覆盖下一轮。请求不附带完整家庭档案、画像、撤销历史或备份库。
- 语音文本由通过校验的操作生成，模型不能自由声称“画好了”。无效JSON、对象、属性、版本、未请求的清空/删除均拒绝；这个检查只保证协议有效，不能保证模型完全理解了每句话。
- `illustrationScene.js`：现有SVG/Rough.js增量节点更新。只绘制本地审核路径；不为这轮重写到新的画布框架。积木仍使用Konva。
- `localStudentDb.js`：保存经过验证的v2快照，包含关系与有限撤销历史；不新增录音收集或云上传。
- 最大8个对象；地面和天空各3个位置，缩放0.65–1.2；位置仍为离散安全槽位，不是自由拖拽布局或智能避让。
- `drawingTimeline.js`：一个批次只提交一次最终状态及撤销历史；派生最多8个语句和画面快照。新对象的初始改色/缩放/相对位置合并展示，避免先闪现错误默认属性。`presentation.initialObjects` 与 `frames` 有严格数量、对象结构及最终一致性校验；旧单步快照仍可读取。
- `illustrationScene.js` 将最终存储状态与正在显示的帧分开；多步时 `prepare` 保留上轮画面，音频 `onStart` 调用 `step(index)`；单步不隐藏已经执行的结果，不依赖TTS及时开始。同一句内是一组变化，不是逐词或逐笔追随音频。小路与房子共用360ms位置插值；减少动态效果时立即到位，多步仍等待对应音频开始。
- `drawingReplyGuard.mjs` 在普通聊天发布前拦截有限的无执行绘画承诺；画布规划器的已验证语句不经过此拦截。自然改色和确认/查看续话优先本地处理，保留原画；真正换话题仍退出。
- 语音关闭或播放失败时，以1200ms间隔顺序展示；重放沿用静音回看，不额外生成模型请求。停止/切换时取消旧计时器与动作，并显示已提交的最终画面，避免下一轮模型状态与画面不一致。存档保存的是操作结果，不代表孩子已听完或理解了所有步骤。
- `voiceService.js` 保留首句流式路径。当前句开始后，最多预备下一句MP3，最大120字、512KB、12秒截止；进入下一句复用结果。换话、暂停或结束会取消未使用预备；失败退回现有语音路径。预备不新增录音上传，但中途打断可能有一条已计费的未播放语音。
