# 家庭测试：在手机上通过局域网使用小宇记

适用场景：电脑和手机（iPhone 或安卓）连在同一个 Wi-Fi 下，在电脑旁边做小范围测试。不经过公网，也不需要部署服务器。

手机浏览器（iPhone 的 Safari、安卓的 Chrome）只允许 HTTPS 页面使用麦克风，所以要先在电脑上生成一个“只在这台电脑上使用”的证书，并在测试用的手机上信任它一次。

## 1. 在电脑上启动（每次测试）

```bash
npm run pilot:lan
```

终端会显示：

- **手机打开的地址**，例如 `https://192.168.1.251:4443/`。电脑换了网络、地址变了也没关系，脚本会自动重新签发证书。
- **访问码**（8 位）。每台设备第一次打开时输入一次。
- **证书文件的位置**：`.certs/xiaoyuji-local-ca.crt`。

如果 macOS 弹出“是否允许 node 接受传入的网络连接”，选“允许”。按 Ctrl+C 结束。

## 2. 手机首次准备（每台手机只做一次）

### iPhone

1. 在电脑上把 `.certs/xiaoyuji-local-ca.crt` 用 **隔空投送** 发到 iPhone，选择“接受”。
2. iPhone 打开 **设置**，最上方出现“已下载描述文件”，点进去，选 **安装**，输入手机密码。
3. 打开 **设置 → 通用 → 关于本机 → 证书信任设置**，把 **Xiaoyuji Local Pilot CA** 打开（完全信任）。少了这一步，Safari 会提示连接不安全。

### 安卓

请用 **Chrome**（或 Edge）。微信里打开的页面和部分手机自带的浏览器，可能不认这张证书，也可能用不了麦克风。

**不装证书（2026-11-12 已在安卓上验证可用）**：Chrome 打开第 1 步显示的地址，出现“您的连接不是私密连接”时，点 **高级 → 继续前往 192.168.x.x（不安全）**，之后照常输入访问码、允许麦克风，麦克风和通话都能用。Chrome 会记住这个选择一段时间，过期或重启后可能要再点一次。只对这台电脑显示的地址这样做；其他网站出现这个警告时不要继续。

**装证书（以后不再出现警告）**：

1. 在电脑上把 `.certs/xiaoyuji-local-ca.crt` 发到手机（微信“文件传输助手”、邮件或数据线都可以），保存到手机的“下载”文件夹。**只发这一个文件**：同一目录里的 `ca.key` 是私钥，不能发给任何人。
2. 打开手机 **设置**，在顶部搜索“CA 证书”或“安装证书”，进入 **安装证书 → CA 证书**。系统提示风险时选“仍然安装”，再选刚才保存的文件。手机没有锁屏密码时，系统会要求先设一个。各品牌的路径大致是：
   - 小米：密码与安全 → 系统安全 → 加密与凭据 → 安装证书
   - 华为/荣耀：安全 → 更多安全设置 → 加密和凭据 → 从存储设备安装
   - 三星：安全和隐私 → 更多安全设置 → 安装证书
   - Pixel：安全与隐私 → 更多安全与隐私设置 → 加密与凭据 → 安装证书
3. 彻底关掉 Chrome 再打开。少了这一步，Chrome 可能仍提示连接不安全。

## 3. 开始测试

1. iPhone 用 Safari、安卓用 Chrome 打开第 1 步显示的地址。
2. 输入访问码，点“连接”。这台手机 12 小时内不用再输入。
3. 进入家长区，在 **麦克风** 里点“允许并读取麦克风”，浏览器弹窗时选“允许”。可以先“录一小段”试听，确认收音正常。
4. 按测试方案开始聊天。

## 4. 测试结束：导出数据

1. 进入家长区，打开 **测试数据**，点 **导出测试数据**，iPhone 保存在“文件”App，安卓一般在“下载”文件夹。
2. 把文件发回电脑（iPhone 用隔空投送，安卓用微信或数据线）。
3. 点 **清空**，准备下一位家庭。

导出文件里**只有**：每轮各阶段的耗时、失败原因代码、粗略的设备类型（例如“iOS 18.2 / Safari”）和屏幕尺寸。**没有**录音、文字、孩子说的话、姓名或具体时间。在同一个标签页里刷新页面，数据不会丢；关闭标签页后数据会清除。

## 5. 安全须知

- **测试期全程结束后，请从手机上删除证书**：iPhone 在 设置 → 通用 → VPN 与设备管理 → Xiaoyuji Local Pilot CA → 移除描述文件；安卓在 设置 → 加密与凭据 → 用户凭据 → Xiaoyuji Local Pilot CA → 删除（可以在设置里搜索“用户凭据”）。信任这张证书的手机，会相信任何用它签发的网站证书。签发用的私钥只在这台电脑的 `.certs/` 目录里，不要拷贝、上传或发给别人。
- 访问码只给当场测试的家长。同一 Wi-Fi 下的其他设备没有访问码就打不开页面，也调用不了语音识别。同一台设备连续输错 8 次，这台设备会被锁定 10 分钟，其他设备不受影响。
- 孩子说的话仍会经这台电脑发送到阿里云做识别和回答，和在电脑上使用时一样。**测试前必须取得家长的知情同意。**
- 服务只在运行 `npm run pilot:lan` 期间对局域网开放。平时用 `npm start` 之类的方式启动时，服务只能在本机访问。

## 常见问题

| 现象 | 处理 |
|---|---|
| Safari 提示“此连接非私人连接” | 第 2 步的“证书信任设置”没打开，或者装的不是当前这台电脑生成的证书 |
| 安卓 Chrome 提示“您的连接不是私密连接” | 没装证书时这是正常的，点“高级 → 继续前往”即可。装了证书还出现：证书没有装成“CA 证书”（装成了“VPN 和应用”或“WLAN”证书），或者装完没有重开 Chrome；也可能用的不是 Chrome |
| 打不开页面 | 确认两台设备在同一个 Wi-Fi 下；访客网络或开启了“设备隔离”的路由器会阻止互访；检查 macOS 防火墙是否允许 node |
| 能打开但麦克风不可用 | 地址必须是 `https://`；在 iPhone 设置 → Safari → 麦克风中检查权限；安卓点 Chrome 地址栏左侧的图标 → 权限，打开麦克风 |
| 提示“尝试次数过多” | 等 10 分钟，或者在电脑上重启 `npm run pilot:lan` |
