# 家庭测试：在 iPhone 上通过局域网使用小宇记

适用场景：电脑和 iPhone 连在同一个 Wi-Fi 下，在电脑旁边做小范围测试。不经过公网，也不需要部署服务器。

iPhone 上的 Safari 只允许 HTTPS 页面使用麦克风，所以要先在电脑上生成一个“只在这台电脑上使用”的证书，并在测试用的 iPhone 上信任它一次。

## 1. 在电脑上启动（每次测试）

```bash
npm run pilot:lan
```

终端会显示：

- **手机打开的地址**，例如 `https://192.168.1.251:4443/`。电脑换了网络、地址变了也没关系，脚本会自动重新签发证书。
- **访问码**（8 位）。每台设备第一次打开时输入一次。
- **证书文件的位置**：`.certs/xiaoyuji-local-ca.crt`。

如果 macOS 弹出“是否允许 node 接受传入的网络连接”，选“允许”。按 Ctrl+C 结束。

## 2. iPhone 首次准备（每台手机只做一次）

1. 在电脑上把 `.certs/xiaoyuji-local-ca.crt` 用 **隔空投送** 发到 iPhone，选择“接受”。
2. iPhone 打开 **设置**，最上方出现“已下载描述文件”，点进去，选 **安装**，输入手机密码。
3. 打开 **设置 → 通用 → 关于本机 → 证书信任设置**，把 **Xiaoyuji Local Pilot CA** 打开（完全信任）。少了这一步，Safari 会提示连接不安全。

## 3. 开始测试

1. iPhone 用 Safari 打开第 1 步显示的地址。
2. 输入访问码，点“连接”。这台手机 12 小时内不用再输入。
3. 进入家长区，在 **麦克风** 里点“允许并读取麦克风”，Safari 弹窗时选“允许”。可以先“录一小段”试听，确认收音正常。
4. 按测试方案开始聊天。

## 4. 测试结束：导出数据

1. 进入家长区，打开 **测试数据**，点 **导出测试数据**，文件会保存到 iPhone 的“文件”App。
2. 把文件用隔空投送发回电脑。
3. 点 **清空**，准备下一位家庭。

导出文件里**只有**：每轮各阶段的耗时、失败原因代码、粗略的设备类型（例如“iOS 18.2 / Safari”）和屏幕尺寸。**没有**录音、文字、孩子说的话、姓名或具体时间。在同一个标签页里刷新页面，数据不会丢；关闭标签页后数据会清除。

## 5. 安全须知

- **测试期全程结束后，请从 iPhone 上删除证书**：设置 → 通用 → VPN 与设备管理 → Xiaoyuji Local Pilot CA → 移除描述文件。信任这张证书的手机，会相信任何用它签发的网站证书。签发用的私钥只在这台电脑的 `.certs/` 目录里，不要拷贝、上传或发给别人。
- 访问码只给当场测试的家长。同一 Wi-Fi 下的其他设备没有访问码就打不开页面，也调用不了语音识别。连续输错 8 次会锁定 10 分钟。
- 孩子说的话仍会经这台电脑发送到阿里云做识别和回答，和在电脑上使用时一样。**测试前必须取得家长的知情同意。**
- 服务只在运行 `npm run pilot:lan` 期间对局域网开放。平时用 `npm start` 之类的方式启动时，服务只能在本机访问。

## 常见问题

| 现象 | 处理 |
|---|---|
| Safari 提示“此连接非私人连接” | 第 2 步的“证书信任设置”没打开，或者装的不是当前这台电脑生成的证书 |
| 打不开页面 | 确认两台设备在同一个 Wi-Fi 下；访客网络或开启了“设备隔离”的路由器会阻止互访；检查 macOS 防火墙是否允许 node |
| 能打开但麦克风不可用 | 地址必须是 `https://`；在 iPhone 设置 → Safari → 麦克风中检查权限 |
| 提示“尝试次数过多” | 等 10 分钟，或者在电脑上重启 `npm run pilot:lan` |
