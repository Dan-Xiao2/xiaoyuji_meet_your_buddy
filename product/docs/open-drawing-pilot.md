# 开放画图与精确白板

2026-10-05最新状态：用户再次授权后，本机图片通道已开启；示例配置仍默认关闭。两批各6次虚构图片测试已完成，账号和页面出图可用，但连续编辑质量未通过验收，详见 `open-drawing-live-benchmark.md` 与 `zebra-live-benchmark.md`。

## 当前实现

- 2026-10-05 对话验收补充：`我想画仙人掌` 不再被当作普通聊天；补充场景进入路由并保留完整要求。“直接画吧/再试一次”使用同一会话的未完成要求，刷新可恢复；取消或转话题后清除。听音确认本地回应，不主动回到上一张画。关闭图片通道时明确说明未生成，路由失败明确重试，不归咎于用户没说清楚。
- 催促/听音确认和失败绘画不新增成长片段；旧控制原话不删除，读取时排除成长回看。这里是有限操作意图过滤，不声称理解所有自然语言或全面清洗旧推测。
- 简单房子、改色、移动、门窗和数积木沿用原有精确执行器。
- 不认识的绘画对象、不完整的本地解析，以及既有图片的后续话语进入 `/api/whiteboard/route`。Qwen文本模型判断精确操作、开放生成/编辑、普通聊天或澄清；不得只执行识别到的一半要求。
- `/api/whiteboard/image` 在服务端持有Key，调用阿里云千问图像生成/编辑接口。默认 `qwen-image-2.0`，不自动切换地区。当前账号及地区已在6次虚构图片请求中验证可调用。
- 编辑传入实际上一张图片；精确SVG先在浏览器转为栅格图。转成图片后不再把其中的物体当作可精确修改的原对象。撤销可以返回转图之前的精确白板。
- 生成独立于语音轮次。普通聊天不取消绘画；新绘画、停止画画、结束会话、恢复备份、离开页面取消旧任务，迟到结果不发布。原图未完成时的新编辑明确请稍等，不假装已排队执行。
- 返回图片完成解码/压缩后才发布；失败保留原图。图片不会被送入普通文字Tutor请求。
- 图片发布前由独立视觉模型检查低幼安全、要求是否可见实现，以及编辑是否明显破坏未要求部分。任何一项不通过或复核不可用都不发布新图，并保留原图。复核只接收绘图要求、生成图和编辑时的原图，不接收家庭档案、录音或完整聊天。
- 当前图画和最多三步历史以受限JPEG随本机状态保存；支持手动下载JPG。成长片段暂不自动复制图片，以免迅速耗尽localStorage；这不等于完整长期图片作品库。完整备份包含当前状态，但现有恢复流程会重置会话画面，重要作品请用下载图画保存。后续专门建设本地图片库及作品附件迁移。

## 启用与费用

开发者环境变量：`IMAGE_DRAWING_ENABLED=true`、`QWEN_IMAGE_MODEL=qwen-image-2.0`，复用 `QWEN_API_KEY` 与 `QWEN_BASE_URL` 的地区。重启服务生效。

已按用户明确授权修改本机 `.env` 并重启服务。第二批6次虚构图片请求已完成，未上传家庭录音或聊天；本轮测试额度已用完，费用待账单核对。用户手动绘画现在会调用图片生成和一次视觉复核，均可能产生接口费用。当前仅供成人陪同本地试用；自动复核已经接入，但尚未完成独立图片安全评测，不作为发布验收通过。

本地接口限制同源请求、单个在途图片任务、请求与图片体积、60秒模型等待；输入先走已有安全规则和有限图片敏感词。只下载阿里云OSS域名的PNG，不跟随重定向、不接受任意远程图片地址。视觉复核失败关闭，但仍不是生产鉴权或完整儿童图像审核：上线仍需账户授权、家庭配额、速率限制、独立安全集及抽样人工复核。

## 验收

已完成的模拟测试：3种宽度390/768/1440，精确房子改色 → 加草地触发图片 → 等待时聊天 → 带原图编辑 → 撤销 → 失败保留 → 刷新恢复 → 下载 → 撤销回精确图；原有语音绘画回归保留。

这些测试证明软件流程，不证明图片模型听懂、画得对或速度足够。待真实账号以虚构素材测：红太阳+草地+房子；屋顶变蓝；添穿雨靴的孩子；移动该人物；删除；撤销。记录总耗时、要求完成情况、未指定部分是否改变、账单费用。不能把接口成功当作语义正确。

下一步：允许范围内的真实模型比较；失败/内容审核；生成等待时继续补充要求的合并策略；作品在本地独立存储并关联成长片段；更精确的局部编辑与图片-对象混合图层。暂不承诺任意内容、完美局部保持或瞬时出图。
