# 阿里云 AI 实时互动对接验证：部署与设置步骤

> 目的：验证“RTC 通话 + 小宇记自己的回答逻辑”在 iPhone 上的效果和延迟。仅成人验证，不连接家庭档案。
> 账号：阿里云国内站。地域：智能体和函数计算都选 **华东2（上海）**，百炼模型照旧在北京。
> 费用：AI 实时互动按通话分钟计费（国内约 0.11 元/分钟，含通话费）；函数计算有每月免费额度；模型费照旧。

## 结构

```
iPhone Safari（rtc-lab.html，阿里云通话界面）
   ⇅ 声音（阿里云 RTC）
阿里云智能体：识别 → 大模型节点 → 语音合成
                    ⇅ HTTPS（OpenAI 流式格式，带密钥）
函数计算 Web 函数：server/rtcLlmServer.mjs → 现有快速回答（安全拦截、科学核对、兜底）→ 百炼 qwen3.8-max
```

回答接口只做一件事，不记录对话内容，没有其他接口。

## 一、准备接口密钥（本机）

在终端生成一个随机密钥，复制备用（不要发到聊天里）：

```bash
openssl rand -hex 24
```

这个值要填两处：函数计算的环境变量 `RTC_LLM_KEY`，以及智能体大模型节点的 API-KEY。

## 二、打包

```bash
npm run rtc:package
```

生成 `dist/rtc-llm.zip`，内容只有打包后的回答服务和知识卡片，不含 `.env` 和任何密钥。

## 三、函数计算

1. 打开 [函数计算控制台](https://fcnext.console.aliyun.com/)，地域选 **华东2（上海）**。
2. 创建函数 → **Web 函数**（只有 Web 函数支持流式返回）。
3. 运行环境选 **自定义运行时 / Node.js / Node.js 22（Debian 11）**，不选带“公测中”的。
4. 代码上传方式选“通过 ZIP 包上传代码”，上传 `dist/rtc-llm.zip`。
5. 启动命令选“命令模式”：`node /code/server/rtcLlmServer.mjs`，监听端口 `9000`。
   不要写 `/var/fc/lang/nodejs22/bin/node` 这样的完整路径：2026-11-10 实测该路径不存在，实例启动失败（CAFileNotFound）。
6. 规格：0.35 vCPU、512 MB 即可；执行超时 60 秒；单实例并发 20；最小实例数先填 0。
   高级配置：函数角色留空；“允许默认网卡访问公网”保持打开（要连百炼）；日志监控建议打开，链路追踪关闭。
7. 环境变量：
   - `QWEN_API_KEY`：百炼 API Key（和本机 `.env` 里的相同）。密钥很长，不要在文本编辑器里手选；用
     `grep '^QWEN_API_KEY=' ~/xiaoyuji/product/.env | cut -d= -f2- | tr -d '\n' | pbcopy` 复制，再在值一栏 Cmd+A、Cmd+V。
   - `RTC_LLM_KEY`：第一步生成的密钥
   - `TUTOR_QUICK_TIMEOUT_MS`：`6000`（和本机一致。不填时默认 3.5 秒内没出第一句就用兜底回答，函数刚启动时容易超时）
8. 触发器：Web 函数自带的 defaultTrigger 默认是“签名认证”，要在“触发器”标签页里编辑改成“无需认证”（接口自己校验密钥），请求方法至少含 GET 和 POST。
9. 创建后复制公网访问地址（形如 `https://xxxx.cn-shanghai.fcapp.run`）。
10. 在浏览器打开 `公网地址/rtc/health`，看到 `"keyConfigured":true` 和 `"modelKeyLooksValid":true` 就说明部署成功（后者为 false 表示 `QWEN_API_KEY` 不是 `sk-` 开头的真实密钥，例如误填了说明文字）。`build` 是安装包的版本，用来确认新包已部署。
    默认域名在浏览器里可能会变成下载一个文件，打开文件看到同样内容即可。

可选：测试期间把“最小实例数”设为 1，避免第一句话遇到冷启动；测完改回 0，否则空闲实例会计费。

## 四、AI 实时互动智能体

1. 打开 [智能媒体服务控制台](https://ims.console.aliyun.com/)，地域 **华东2（上海）**，进入 AI 实时互动 → 智能体管理。
2. 创建智能体，类型选 **音频通话**。
3. 编辑它的工作流：
   - 语音识别节点：保持预置。
   - 大模型节点：选 **自研接入（OpenAI 规范）**
     - 模型 ID：`xiaoyu`
     - API-KEY：第一步生成的密钥
     - 服务地址：`公网地址/rtc/v1`（平台会自动在后面加 `/chat/completions`）
   - 语音合成节点：选和网页语音相同的音色，即 `.env` 里 `QWEN_TTS_VOICE` 的值（默认 `longanhuan_v3.6`），可调语速和音调。以后换音色时，两边要一起改，小宇的声音才一致。
   - 保存并发布工作流，绑定到智能体。
4. 智能体设置：打开 **智能打断**；欢迎语可以写“你好呀，我是小宇。今天想聊什么？”。
5. 如果有“录制”“数据归档”之类的开关，保持关闭（符合“只在本机保存”的承诺）。
6. 在智能体列表点 **Demo 体验二维码**，过期时间选 1 天，生成并复制体验 Token。

## 五、在 iPhone 上试

1. 电脑上保持试点服务器运行（`npm run pilot:lan`）。
2. iPhone Safari 打开 `https://192.168.1.251:4443/rtc-lab.html`（已配对的设备不用再输访问码）。
3. 粘贴体验 Token（用“通用剪贴板”从 Mac 复制最方便），勾选同意，点“开始通话”。
4. 戴耳机，照 [儿童视角测试对话](rtc-child-dialogue-test.md) 逐段说：插话打断、说“嗯”、追问后音量、回答是不是小宇的风格、说完到开口等多久。手机外放时 iPhone 会炸音、安卓会断续（见 [手机外放调研](rtc-phone-speaker-research.md)），外放只用来复测系统更新后是否修好。结果记在那份文件末尾的测试记录里。

在伦敦测时，声音要经过伦敦到上海的通话网络，等待会比国内家庭实际感受到的略长。

## 六、测完

- 函数计算的最小实例数改回 0；不用了可以删除函数。
- 体验 Token 到期自动失效。
- 验证阶段的限制：体验 Token 不能传孩子资料（年龄段用默认 4–5 岁），成长记录和画画暂不接入；正式接入时由我们的服务端开始通话并传入资料。

## 七、正式接入：孩子页面的通话模式

验证页用的是控制台的体验 Token；正式接入改由试点服务器开始通话（`POST /api/rtc/call`），孩子页面点小宇就打通、再点挂断。

1. 打开 [RAM 访问控制](https://ram.console.aliyun.com/) → 权限策略 → 创建权限策略 → 脚本编辑，粘贴：
   ```json
   {"Version":"1","Statement":[{"Effect":"Allow","Action":"ice:GenerateAIAgentCall","Resource":"*"}]}
   ```
   命名为 `xiaoyu-rtc-call`。
2. 用户 → 创建用户，例如 `xiaoyu-rtc`，勾选“使用永久 AccessKey 访问”（不要控制台登录）。创建后把 AccessKey ID 和 Secret 保存好（只显示一次，不要发到聊天里）。
3. 给这个用户添加权限：只选上一步的 `xiaoyu-rtc-call`。
4. 在本机 `.env` 加四行（值自己填）：
   ```
   ALIYUN_ACCESS_KEY_ID=
   ALIYUN_ACCESS_KEY_SECRET=
   RTC_AGENT_ID=智能体 ID（智能体管理列表里）
   RTC_REGION=cn-shanghai
   ```
5. 重启试点服务器（`npm run pilot:lan`）。如果 `src/rtc/aicall.bundle.js` 不存在，先运行 `npm run rtc:build`。
6. 手机上：家长 → 家庭设置 → 设备与测试 → 实验功能 → 打开“通话模式（需戴耳机）”。没配好密钥时这个开关不显示。
7. 回到家长首页点开始聊天：通话模式下这一下就直接接通，显示“正在接通”→“我在听”。只请求麦克风，不请求摄像头。说话、插话照常；点小宇挂断，再点重新接通。

通话模式里：
- 每轮孩子的话和小宇的回答按字幕存进本机记录，和原来一样进成长记录；被打断的回答标记为打断。
- 开始通话时带上和网页回答相同的有上限摘要（名字、年龄段、兴趣、家长目标、最近 6 个兴趣和 4 件做到的事、通话前最近 6 句，每句最多 200 字），放在通话的 userData 里，每轮由阿里云转给函数计算。摘要不随档案变大；成长记录、家长内容和照片不上传。
- 函数计算要部署 build `2026-11-11a` 或更新的包才会用上摘要（`npm run rtc:package` 后重新上传）。
- 每轮存下后，和网页语音一样在后台把“孩子原话 + 小宇已说的回答”交给本机服务器（`/api/tutor`，经百炼，不经阿里云）提取成长证据和兴趣，更新这条成长记录和本机记忆。按回合顺序一次一个，不影响通话。
- 通话中不画白板；要画画时切回普通模式。
- 离开孩子页面、锁屏切走或家长结束聊天时自动挂断。
- 通话开着时，页面自己的“自动听”不打开麦克风，页面自己的播放通道（AudioContext）也先关掉，声音只走通话组件；两个同时运行在 iPhone 上会有电流声。
- iPhone 如果提示“点一下屏幕就能听到小宇”，点一下即可听到声音，这一下不会挂断。
- 每轮的识别、大模型、合成耗时和“说完到开口”记进试点测量（家长 → 设备与测试 → 导出测量），只有数字。阶段名：`rtc-asr`、`rtc-llm`、`rtc-tts`、`speech-to-reply`、`response-start`（智能体总耗时）。
- 通话超过 1 小时会自动续期凭证。

## 出问题时

| 现象 | 先查 |
|---|---|
| `/rtc/health` 打不开 | 返回 `CAFileNotFound`：启动命令写成 `node /code/server/rtcLlmServer.mjs`；其他情况看“日志”标签页，并核对端口 9000 |
| 返回签名错误 | 触发器认证方式还是“签名认证” |
| `keyConfigured` 为 false | 函数环境变量 `RTC_LLM_KEY` |
| 通话能接通但小宇不回答或回答很笼统 | 大模型节点的地址是否以 `/rtc/v1` 结尾、API-KEY 是否一致；`QWEN_API_KEY` 是否正确（错误时会用兜底回答“我听到了。我们一起想一想。”） |
| 第一句特别慢 | 冷启动：最小实例数设为 1 |
| 通话模式开关不显示 | `.env` 四项是否都填了、服务器是否已重启 |
| 点小宇后提示“通话断开了” | 服务器终端里的 `RTC call not started:` 后面的代码：`Forbidden.RAM` 是权限策略没加到用户；`InvalidAccessKeyId` 是 AccessKey 填错 |
| iPhone 外放有电流声（炸音） | iOS 26.2–27 的 Safari 已知问题（WebKit 326286），网页端修不了。戴耳机就不炸；孩子默认用网页语音。见 [手机外放调研](rtc-phone-speaker-research.md) |
| 安卓外放音量忽小、说话断续、打断慢 | 外放时手机的回声处理造成的，戴耳机就正常。见 [手机外放调研](rtc-phone-speaker-research.md) |
| 只回“我听到了。我们一起想一想。” | 函数“日志”里搜 `rtcReply`：`message` 是超时就加 `TUTOR_QUICK_TIMEOUT_MS=6000`；是 API-key 相关错误就核对 `QWEN_API_KEY` |
