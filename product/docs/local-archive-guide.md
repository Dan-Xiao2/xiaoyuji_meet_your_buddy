# 本地记录整理与恢复

## 家长怎么用

1. 先结束聊天，再打开左上角菜单中的“备份记录”。桌面在顶部导航进入同一页。
2. 找到一条记录，点击“整理”。可以修正原话、主题和领域，补充备注，确认记录，或取消“计入成长回看”。
3. 删除需要再次确认。取消操作不会改动记录；已下载到其他文件夹或设备的副本需要自己删除。
4. 点击“完整备份”下载 JSON。单条/多条下载适合阅读，不是完整恢复文件。
5. 展开“数据设置”，点击“恢复完整备份”。先核对孩子、记录数量和日期，再确认替换。恢复不会自动开启聊天或麦克风。
6. “清空本地数据”会先要求确认，设置了家长码时需先解锁。“保留资料”或Esc不会删除；资料在确认期间变化时需要重新确认。清空失败会留在弹窗中提示，不会显示成功。

## 无法读取记录时

- 小宇记会先停在恢复页面，不把损坏记录显示成“还没有记录”，也不启动聊天。
- 先下载“原始恢复文件”留在自己设备上。这是保留现场的私人资料，不是可直接恢复的完整备份，不要公开上传。
- 选择以前下载的完整备份，核对预览后确认替换；有可用本机副本时也可以选择。没有有效副本时不要清理浏览器数据。
- 看到“本机备用保存暂不可用”时，已有主记录不一定丢失，但不能依赖备用副本。先下载完整备份；它和普通保存失败是不同提示。

## 当前限制

- 主记录仍在这个浏览器的localStorage内，另有IndexedDB本机备用副本；两者都不是自动保存到电脑文件夹。清理浏览器前请下载完整备份；其他设备可通过手动传输完整JSON后恢复，尚无自动云同步。
- 恢复是替换，不是合并。建议先下载当前备份；只支持完整 v3 格式，一个孩子和最多六位照护者。上传上限为10MB，但实际可写入量还受浏览器配额影响。
- 备份没有额外加密，含家庭设置、成长原话和本地家长码摘要，请保存到家长自己控制的位置，不要公开上传。
- 原话、主题、领域或回看选择变化后，旧自动画像与会话总结会保守重置，因为旧代码没有完整的逐条来源关系。其他原始成长片段与独立线下观察保留，之后从新证据继续积累。
- 恢复保留档案记录和模型，不继续原先的聊天画面或进行中的活动。合并、照片附件、说话人纠错、任意旧格式迁移和更细粒度画像重算留待后续。
- 保存日志支持失败回滚及中断恢复。其他标签收到整理/恢复通知会刷新，但还不应在多个标签里同时录入或恢复档案。
- 清空会取消当前对话和播音，旧备用副本不能自动重新出现。但删除备用副本也可能失败，不能据此承诺已经彻底擦除；已下载的文件需自己处理。

## 自动验证

- `npm run check:archive`：导出恢复、错误文件、编辑/确认/排除/删除、超过500条记录、失败回滚、转义与成长回看。
- `npm run check`：包含上述检查、知识卡/架构校验和现有产品回归检查。
- `npm run check:release`：还包含正式页面与档案故障浏览器回归；覆盖损坏资料、恢复日志、备用保存失败、旧标签写回及清空时的在途请求。
- `tests/archive-browser.mjs`：使用独立浏览器环境和模拟数据，屏蔽所有 API 调用；验证390px、1440px下的实际操作和刷新保留。
- 浏览器测试需要 Playwright 及可启动的 Chromium/Chrome。可通过 `PLAYWRIGHT_MODULE` 指向已安装模块，`CHROME_PATH` 指向浏览器，`TEST_URL` 指向测试服务器；不会使用用户现有浏览器的本地数据。
- 真机录音、儿童语音、家长理解度、真实跨周价值不包含在以上自动验证中。
