# 语音真机测试清单（2026 年 11 月，全双工第一步）

> 目的：在真机上量出开口打断和等待时间，决定外放时打断的默认值，以及下一步走哪条路线（见 `docs/improvement-plan-2026-11.md` 阶段 1）。
> 测试前：家庭设置 → 设备与测试 → 测试数据 → 清空；每格测完导出一次，文件名注明格子（例如 `外放安静-成人`）。

## 这一版改了什么（要验证的）

- **回声不算打断**：小宇说话时，识别出的内容如果是她自己正在说的话，不让她停。
- **“嗯 / 对 / 好”不算打断**：孩子只是附和，小宇接着说，这句也不发给小宇。
- **按语义等孩子说完**：问句（……吗 / ……呢 / ……？）停顿约 0.55 秒就回答；说到一半（……然后 / ……因为 / ……，）多等到约 1.8 秒；其他仍是 1.05 秒。

## 测试格子

| 格子 | 设备摆放 | 说话的人 |
|---|---|---|
| 1 外放·安静 | iPhone 放桌上，音量约 60% | 成人，孩子 |
| 2 外放·有噪音 | 同上，旁边放电视或音乐 | 成人，孩子 |
| 3 AirPods | 戴耳机 | 成人，孩子 |

每格各做：

1. **10 次开口打断**：小宇说第二句时直接说一句完整的话（例如“我想看蚂蚁”）。记下：她停没停、停得快不快。
2. **5 次附和**：小宇说话时只说“嗯”或“对”。她应该继续说。
3. **5 次不出声**：小宇说话时不说话，旁边拍手或关门一次。她应该继续说。
4. **10 轮普通对话**：其中至少 3 次用问句（“……为什么呢？”），3 次故意说到一半停一下（“我看到一只蜗牛，然后……”）。记下：问句是不是回得更快；说到一半时有没有被抢话。

## 导出数据里看什么

| 数据 | 含义 | 希望 |
|---|---|---|
| `barge-in` | 检测到有声音，小宇先变小声 | — |
| `barge-in-confirmed` | 确认是孩子，小宇停下 | 第 1 项接近 10/10 |
| `barge-in-dismissed` | 不是孩子，小宇恢复音量继续说 | 第 2、3 项都在这里 |
| `barge-in-echo` / `echo-suppressed` | 识别到小宇自己的声音，被挡住 | 外放时出现说明回声消除不够干净 |
| `barge-in-backchannel` / `backchannel-suppressed` | 只是“嗯 / 对”，被挡住 | 对应第 2 项 |
| `endpoint-hint` | 说完提示：complete / unfinished | 问句和半句各自出现 |
| `endpoint` | 实际等了多久才判定说完 | 问句约 550，半句约 1800 |
| `response-start` | 说完到小宇开口的总时间 | 记 p50 和 p90 |

## 测完要决定的

- 外放时开口打断默认开还是关（误打断多就默认只允许点按打断，耳机保持开启）。
- 回声被挡住的次数多不多：多的话，外放的回声消除是瓶颈，考虑原生外壳或 WebRTC。
- 问句提速后有没有抢话：有的话把 0.55 秒调长。
