# 小宇记家庭试点手册（草稿，2026-11-13）

> 对应 [改进计划](improvement-plan-2026-11.md) 阶段 3 的“试点手册”和阶段 4 的家庭试点。状态：**草稿，待用户审阅**。同意书是按小宇记实际的数据流写的试点用文字，不是法律意见；正式对外试用前要做专门的合规审查（[产品框架](product-framework.md) 第 12 节）。
>
> 内容：一、试点要回答什么；二、开始前要定的事；三、流程；四、监护人知情同意书（可打印）；五、观察记录表；六、每周 10 分钟家长访谈提纲；七、每周汇总；八、立即停止的情况；九、结束与删除。

## 一、试点要回答什么

试点用数据回答改进计划里的四个问题：

1. 孩子主动发起的聊天里，小宇的回答是否跟题？孩子纠正时是否被接住？
2. 没有大人催促时，孩子会不会再次发起？
3. 家长是否保存、修改或回看至少一条记录，并觉得它留下了自己可能错过的孩子视角？
4. 听错、等待、打断、没声音这类技术问题，打断了多大比例的聊天？

结束时按框架第 15 节写一次 Go / Pause / 重新评估定位的判断。家庭数和天数是计划规模，不是通过门槛。

试点**不**回答：家长愿不愿意付费、孩子能用多久、能不能提高某种能力。不用聊天时长、句数多少证明成功。

## 二、开始前要定的事

| 事项 | 为什么要先定 | 选项 | 建议 |
|---|---|---|---|
| 家庭怎么连上小宇记 | 现在只能在运行服务器的电脑所在的 Wi-Fi 里用（`npm run pilot:lan`）。家庭在自己家里连不上，就测不了第 2 个问题“自己会不会再来” | A 住在一起或常在同一 Wi-Fi 的亲友；B 上门或来访，每周 2–3 次，每次 10–20 分钟；C 先做境内部署再试点（要定服务器、域名、访问控制，可能涉及备案，至少约 1 周） | 有 A 类家庭就先从 A 开始，可以配一两家 B。B 类家庭的第 2 个问题标“无法回答”，不要硬算。**用户 11-13 选择先做 C**，方案见 [deployment-cn.md](deployment-cn.md) |
| 家庭数和年龄 | 计划规模 | 3–5 家，3–6 岁 | 先 3 家熟人家庭，监护人全程在场 |

| 通话模式 | 隐私政策还没写阿里云智能媒体服务和函数计算 | 关 | 试点中保持关闭 |
| 画图（云端生成图片） | 多一项云端处理 | 开或关 | 按现在的 `.env` 保持关闭；要开，先告诉家庭 |
| 同意版本 | 应用内隐私政策 11-13 新增了“使用和测试数据”一条，同意版本仍是 2 | 提高或不提高 | 新家庭第一次设置时会看到新文字，可以不提高；纸面同意书另外覆盖“试点团队收到什么” |
| 资料保存多久 | 同意书要写清楚 | 填期限 | 试点报告完成后 3 个月内删除导出文件和访谈记录 |
| 感谢方式 | 不能用奖励换使用 | 不给、或结束时送一份与使用量无关的小礼物 | 不按次数、天数给奖励 |

## 三、流程

| 时间 | 做什么 | 谁 | 大约多久 |
|---|---|---|---|
| 招募 | 说明试点是什么、要多久、要做什么；把同意书给家长带回去看 | 试点负责人 | 10 分钟 |
| 第 0 天 | 当面讲同意书，回答问题，签字；问孩子愿不愿意（见同意书末尾）；一起完成首次设置：昵称、年龄、隐私确认、试麦；建议设置家长码 | 负责人和家长 | 30 分钟 |
| 第 0 天 | 按[局域网测试说明](pilot-lan-setup.md)连上；家庭设置里检查：开口打断按第二节的结论设置、保存成长记录打开、通话模式关闭 | 负责人 | 10 分钟 |
| 第 1–14 天 | 自然使用：孩子想聊就聊，不设每日任务，不提醒，不比较 | 家庭 | 不限 |
| 每周一次 | 10 分钟访谈（第六节）；家长从家庭设置 → 设备与测试 → 测试数据导出文件发给负责人；负责人填观察记录（第五节） | 负责人和家长 | 15 分钟 |
| 第 14 天 | 结束访谈（第六节最后部分）；家长选择保留还是删除手机里的记录；拿回或卸下证书（安装过的话） | 负责人和家长 | 20 分钟 |
| 结束后 | 写试点报告：四个问题的答案、失败的例子、Go/Pause 判断 | 负责人 | — |

给家长的一句话说明：“这两周请让孩子想聊的时候再聊，不用每天安排。聊得少、不想聊、说‘没用’，对我们一样有用。”

## 四、监护人知情同意书（试点版）

> 打印两份，家长和负责人各留一份。方括号里的内容在打印前填好。

**小宇记家庭试点 · 监护人知情同意书**

版本：试点版 1 · 日期：[2026 年 11 月 __ 日] · 家庭编号：[F_]

**1. 这是什么**

小宇记是给 3–6 岁孩子用的语音陪伴。孩子把自己的发现和问题说给“小宇”听，小宇回应，陪孩子聊下去；家长可以回看孩子说过的话。小宇的回答由人工智能生成，可能不准确，它不替代父母、老师或医生。

这次试点由 [负责人姓名] 组织，想了解：孩子愿不愿意主动来聊，小宇能不能听懂并跟上孩子，家长觉得留下的记录有没有用。

**2. 参加要做什么**

- 时间约 [2 周]，从 [日期] 到 [日期]。
- 孩子想聊的时候再聊，不设每天的任务，不要求聊多久。
- 每周和负责人聊约 10 分钟，并把手机里导出的“测试数据”文件发给负责人。
- 孩子使用时，请有大人在身边或方便照看。

**3. 小宇记会处理哪些信息**

| 信息 | 保存在哪里 | 谁能看到 |
|---|---|---|
| 孩子的昵称、年龄段，家人的称呼，家长码（只存加密后的摘要） | 这台手机的浏览器里 | 使用这台手机的家人 |
| 孩子说的话（转成文字后）、小宇的回答、成长记录、家长写下的观察 | 这台手机的浏览器里 | 使用这台手机的家人 |
| 每次聊天的数字：孩子和家长各说了几句、纠正了几次、怎么结束的、隔几天再来、家长对“有用吗”的回答；每一步的耗时和出错代码 | 这台手机的浏览器里；家长导出后发给负责人 | 家长、负责人 |

**4. 哪些内容会发到云端**

- 聊天进行中，孩子说话的声音会实时发到**阿里云百炼（通义千问，中国内地服务）**转成文字。
- 小宇回答时，会把孩子的昵称、年龄段、家长填写的陪伴偏好、最近 12 句对话和兴趣摘要发给阿里云百炼的模型，生成回答后再转成语音。
- 这些内容经 [负责人] 的电脑转发。这台电脑不保存录音和聊天内容，也不记录内容日志。
- 阿里云按它的服务条款处理这些数据。
- 聊天进行中、小宇在听的时候，麦克风是开着的，旁边家人说话也可能被识别成文字。不想被听到的时候，请先结束聊天。
- 声音一旦发出就无法撤回，事后删除手机里的记录不会删除云端已经处理过的内容。
- 本次试点不使用“通话模式”和云端画图。

**5. 不会做的事**

- 不保存孩子的录音，不录像、不拍照。
- 不需要孩子的真实姓名、幼儿园、住址或照片。请给孩子起一个昵称。
- 负责人不抄写孩子的原话。访谈和报告里用家庭编号，不写孩子和家人的名字。
- 不用于广告，不公开，不出售。

**6. 可能的风险和不便**

- 小宇可能听错、答错，或者回答慢。
- iPhone 外放时，小宇的声音偶尔可能有杂音。
- 孩子可能想多看屏幕。小宇记不设奖励和打卡；觉得用得太多，可以随时停。
- 云端处理的风险见第 4 条。

**7. 如果孩子说了让人担心的话**

小宇会平静地鼓励孩子告诉身边信任的大人。小宇记不会把这类话自动转发给别人；识别出的这类话不会保存进普通的成长记录（识别不一定完整）。负责人如果在访谈中得知孩子可能有危险，会先和您沟通。

**8. 您可以随时**

- 停止使用或退出试点，不需要说明理由，也不会有任何影响。
- 在小宇记里查看、下载和删除记录：“备份记录”页可以下载完整备份，在“数据设置”里清空本地数据。
- 关闭“保存孩子的成长记录”，之后还能聊天，但不再保存新记录。
- 要求负责人删除您发过来的导出文件和访谈记录。

**9. 资料保存多久**

负责人收到的导出文件和访谈记录，在试点报告完成后 [3 个月] 内删除。试点结束时，手机里的记录由您决定保留还是删除。

**10. 联系**

有问题请联系 [负责人姓名 / 微信或电话]。

**请逐项勾选：**

- □ 我是孩子的父母或监护人，已读完本同意书和小宇记里的《用户协议》《隐私政策》，问题已得到解答。

- □ 我同意每周把导出的测试数据文件发给负责人，并接受约 10 分钟的访谈。
- □（可选）访谈时，我愿意在自己的手机上给负责人看某次聊天，负责人只看、不抄写原话。

## 五、观察记录表

沿用 [`templates/manual-validation-record.json`](templates/manual-validation-record.json)：**每个家庭每周一份**，由负责人在每周访谈后填写，文件名如 `F1-第1周.json`，和导出文件一起存放。不写孩子原话和名字（`notesWithoutChildQuotes` 也一样）。

| 字段 | 怎么填 |
|---|---|
| `testId` | 家庭编号加周数，例如 `F1-w1` |
| `date` | 访谈日期 |
| `build.commit` | 试点用的版本：`git rev-parse --short HEAD`，有未提交改动时注明 |
| `build.*Model` | 文本、识别、合成模型名；画图关闭时 `imageModel` 留空 |
| `testType` | `family-pilot` |
| `consentConfirmed` | 纸面同意书已签：`true` |
| `noRawAudioStored` | `true` |
| `device` | 机型类别、系统、浏览器；外放还是耳机写在 `microphone` |
| `session.durationMinutes` | 本周各次聊天 `minutes` 的总和（导出 `sessions`） |
| `session.syntheticUtterances` | `0`（家庭试点没有虚构话语） |
| `session.understoodFirstTime` / `repeatsNeeded` | 访谈里问“小宇听错、要重说的情况”，按家长估计填；不确定就留 `null` |
| `session.firstAudioLatencyMs` | 导出 `summary.stages["response-start"]` 的 p50、p90 |
| `session.topicDrifts` / `repeatedQuestions` | 访谈里家长说到的跑题、反复问的次数 |
| `session.drawingRequests` / `drawingSuccesses` | 孩子要求画画的次数、画出来的次数（访谈或现场） |
| `safety.*` | 访谈第 5 部分；任何一项为 `true`，同时按第八节处理 |
| `familyValue.returnedForAnotherSession` | 本周孩子自己发起的聊天多于 1 次（导出 `initiator: "child"` 或访谈）。B 类来访家庭填 `null` |
| `familyValue.reviewedGrowthRecord` | 家长本周回看过成长记录（访谈） |
| `familyValue.correctedOrDeletedRecord` | 导出 `editedMoments` 合计大于 0，或家长说删过记录 |
| `familyValue.helpedParentChildConversation` | 访谈第 4 部分：是否因为记录和孩子聊起过 |
| `result` | 本周没有阻断问题：`pass`；有阻断问题（听不懂、没声音、崩溃）：`fail`；数据不够：`inconclusive` |
| `blockingIssues` | 阻断问题的简短描述，例如“外放杂音 3 次”“连不上服务器” |

现场观察（第 0 天，或 B 类家庭来访时）另记几条，写进 `notesWithoutChildQuotes`：孩子知不知道什么时候可以说话；小宇是否跟上当前话题；孩子纠正后小宇有没有改；打断有没有用；孩子是否受挫或要大人代说。

## 六、每周 10 分钟家长访谈提纲

原则：问发生了什么，不问“喜不喜欢”；不引导、不替家长下结论；家长可以跳过任何问题；不记孩子原话，只记家长的描述。

| 部分 | 时间 | 问题 |
|---|---|---|
| 1. 开场 | 1 分钟 | 这周大概用了几次？一般是什么时候？ |
| 2. 谁开始的 | 2 分钟 | 通常是孩子自己要找小宇，还是您提议的？有没有哪次孩子自己跑来说“我要跟小宇说”？ |
| 3. 印象最深的一次 | 3 分钟 | 说一次印象最深的聊天：孩子想说什么？小宇有没有接住？孩子说“不是”“不对”的时候，小宇改过来了吗？孩子是怎么结束的？ |
| 4. 记录 | 2 分钟 | 这周看过成长记录吗？有没有收藏、修改或删掉的？有没有一条让您觉得“原来孩子这样想”？有没有因为它和孩子聊起来？ |
| 5. 问题和担心 | 1 分钟 | 有没有听错、等很久、突然没声音、杂音？孩子有没有不舒服、害怕或说过让您担心的话？对数据或小宇有什么顾虑？ |
| 6. 下周 | 1 分钟 | 下周想继续吗？有没有希望我们改的地方？ |

**结束访谈（第 14 天，约 15 分钟）**，在第 6 部分后补问：

- 和两周前比，孩子找小宇的次数是变多、变少还是差不多？您觉得原因是什么？
- 如果没有这次试点，您会让孩子继续用吗？为什么？
- 有哪一条记录是您会想留下来的？
- 小宇有没有让您觉得不放心的地方（比如代替了您、让孩子不想找别人）？
- 您手机里的记录要保留还是删除？

记录方式：负责人当场用几句话记要点，标家庭编号和周数，不录音。

## 七、每周汇总

把每家的导出文件（`sessions` 每次聊天一行，字段见 [value-measurement.md](value-measurement.md)）和访谈要点放在一起，每家一行：

| 指标 | 从哪里来 | 对应问题 |
|---|---|---|
| 聊天次数、有聊天的天数、`daysSincePrevious` | 导出 | 2 |
| 家长说“孩子自己想聊”的次数（`initiator: "child"`）、从孩子页面开始的次数（`entry`） | 导出 | 2 |
| 孩子句数的中位数、有家长代说的次数（`adultTurns` 大于 0） | 导出 | 1、护栏 |
| 纠正次数、下一句没再纠正的次数 | 导出，访谈第 3 部分对照 | 1 |
| 结束方式分布：说再见 / 按结束 / 离开 / 出错后中断 | 导出 | 1、4 |
| 出过错的聊天数（`failures` 大于 0）及占比 | 导出，访谈第 5 部分对照 | 4 |
| “有用 / 一般 / 没用 / 没回答”各几次 | 导出 | 3 |
| 收藏、修改的片段数 | 导出 | 3 |
| 回看、因记录聊起来 | 访谈第 4 部分 | 3 |

读数时：

- 样本很小，写次数，不只写百分比。例如“5 次里 3 次孩子说再见”，不写“60%”。
- 没回答不等于没用；“离开”可能是孩子去做别的事，不一定是失败。
- “纠正被接住”是近似数，以访谈和现场观察为准。
- 技术问题和价值不足分开记。技术问题多到盖住判断时，先修，属于 Pause。

## 八、立即停止的情况

出现下面任何一种，当场停止这次聊天，当天告诉负责人，记进观察记录的 `safety` 和 `blockingIssues`：

- 小宇给出危险建议，或要求孩子保密；
- 连续三次听不懂，孩子明显受挫；
- 孩子明显不舒服、害怕，或说出可能有危险的事；
- 发现数据发到了同意书没写的地方。

负责人处理：先停止该家庭使用，查清原因并修复后再问家长是否继续；涉及安全的情况按框架第 12 节和 [`child-safety-evaluation.md`](child-safety-evaluation.md) 复核。不用参与度抵消安全问题。

## 九、结束与删除

- 家长决定手机里的记录保留还是删除（备份记录 → 数据设置 → 清空本地数据）。想留的可以先点“完整备份”下载。
- 安装过证书的手机，按[局域网测试说明](pilot-lan-setup.md)删除证书。
- 负责人在试点报告完成后 [3 个月] 内删除导出文件、观察记录和访谈记录，并告诉家长已删除。
- 报告里只用家庭编号，不写孩子原话、名字和日期。
