# 境内部署方案（草稿，2026-11-13）

> 目的：试点家庭在自己家里用手机打开小宇记，这样才能测[试点手册](pilot-handbook.md)第 2 个问题“孩子没人催会不会自己再来”。现在只能在运行服务器的电脑所在的 Wi-Fi 里用（[局域网测试说明](pilot-lan-setup.md)）。
>
> 状态（2026-11-13）：用户确认了方案；第三节的代码和部署包已完成，操作步骤见 [`deploy/README.md`](../deploy/README.md)。还没有购买服务，没有部署；隐私文字等部署时再改。

## 一、结论

**推荐**：阿里云轻量应用服务器（华北 2 北京，包年包月 3 个月以上），加一个实名域名，做 ICP 备案，用 Caddy 自动申请 HTTPS 证书，再转给只监听本机的小宇记服务。数据都在境内。地域选北京或上海都可以，差别很小，见第七节（11-13 更正：之前写的“北京延迟最低”说重了）。

**最慢的是备案**：阿里云初审 1–2 个工作日，管局审核 1–20 个工作日，管局阶段不能加急。加上买域名和实名认证，大约 **1–4 周**。代码改动约 1–2 天，可以在等备案时同时做。

不推荐的路线：

| 路线 | 为什么不推荐 |
|---|---|
| 函数计算 | 默认域名会给网页加“下载附件”的响应头，浏览器打不开页面，必须绑自定义域名，一样要备案。实时识别的长连接和边生成边返回的回答也更难放进去 |
| 中国香港或境外节点 | 不用备案，但孩子的声音要先出境再回到北京的百炼，属于跨境传输，和“境内部署”的目的相反 |
| 不用域名，直接用 IP 访问 | Let's Encrypt 从 2026-01 起可以给 IP 地址签发证书（有效期 6 天），技术上做得到；但这样绕开了备案要求，阿里云也可能拦截。不建议 |
| 继续用局域网，另找一台电脑放在家庭家里 | 那台电脑上要放 API 密钥，丢失或被别人用的风险由你承担，也不好维护 |

## 二、你要做的（按顺序）

这些都要用你的阿里云账号和身份信息，我不登录、不经手密码和密钥。

1. 阿里云账号完成个人实名认证。
2. 买轻量应用服务器：**华北 2（北京）或华东 2（上海）**（见第七节），2 核 2 GB 足够（3 个家庭，Node 服务很轻），系统选 Ubuntu 24.04，**包年包月 3 个月以上**（备案要求，续费累计也算）。价格以控制台为准；开发者社区文章说 2 核 2G 有每年几十元的活动价，条件经常变。
3. 买一个域名，完成域名实名认证。**实名信息要和备案主体一致。**
4. 在阿里云备案控制台提交 ICP 备案：
   - **先决定主体**：个人还是公司（见第七节；建议提交前先问阿里云备案客服）。个人备案的网站名称要 3 个以上汉字、和本人有关联；网站内容像企业或产品官网时，可能要求改用单位备案。名称和说明按控制台的指引填写。
   - 要准备身份证照片，按所在省份管局的模板填写真实性核验单。
5. 备案通过后：把域名解析到服务器的公网 IP；在服务器防火墙开放 80 和 443（80 只用来申请证书和跳转到 HTTPS），关闭其他端口，SSH 只用密钥登录。
6. 在这台电脑上生成 SSH 密钥，把公钥加到服务器上。之后的初始化和更新脚本我来写，可以由你运行；你同意的话，也可以由我在这台电脑上运行。
7. 在服务器上放 `.env`，API 密钥由你自己填写。

## 三、我要做的（代码，备案期间同时做）

| 改动 | 为什么 |
|---|---|
| 每家一个访问码，可以单独停用 | 现在全家共用一个码，停不了某一家；用量也分不出是哪家的 |
| 登录状态改成签名的 Cookie，有效期可设（例如 30 天） | 现在登录状态存在内存里，12 小时过期，每次重启或部署所有家庭都要重新输码 |
| 输错锁定改为按来源计算，只锁住输错的那台设备或那个网络 | 现在全局 8 次锁定，放到公网上，任何人都能让所有家庭 10 分钟进不来 |
| 用量上限：每家每天的回答次数、识别分钟、合成次数，以及同时识别的连接数；超出时提示家长，不再调用付费接口 | 防止访问码泄露或程序出错时意外产生费用 |
| 公网模式只开放正式页面 | 测试页（`rtc-lab.html`、`voice-lab.html`、`mic-check.html`）、样板和架构图不需要对外 |
| `/healthz` 健康检查；日志只记错误和次数 | 方便确认服务在运行；不记录内容 |
| 部署包 `deploy/`：Caddy 配置、systemd 服务、服务器初始化和更新脚本、生产环境变量模板（不含密钥） | 部署可以重复，不靠手工 |
| 同步文字：隐私政策、同意书第 4 条、试点手册第二节，把“负责人的电脑转发”改成“阿里云北京服务器转发”；架构图加部署边界 | 文字要和实际数据流一致 |

这些改动在局域网测试里同样有用（每家一个码、重启不用重输、用量上限），备案不通过也不浪费。

**进度（2026-11-13）**：除最后一行“同步文字”外都已完成，见 `server/lanAccess.mjs`、`server/usageLimits.mjs`、`deploy/`，测试 `tests/public-server.test.mjs`。“同步文字”等实际部署时再改，以免文字先于事实。用量到上限时，页面现在只显示一般的失败提示（例如“现在转不成文字”），还没有专门说明“今天用量到上限”。

## 四、费用（粗估）

- 服务器：以控制台价格为准（见第二节第 2 步）。
- 域名：每年几十元，以注册商价格为准。
- 模型和语音：改进计划估算 5 家 × 2 周约 70–130 元；用量上限防止意外超支。
- 证书：Let's Encrypt，免费。

## 五、隐私和合规

- 服务器只转发，不保存录音和聊天内容。Caddy 默认不写访问日志（日志里会有 IP 和网址），保持关闭。
- 声音和对话会从家庭的手机发到北京的服务器，再发到北京的阿里云百炼，都在境内。
- 隐私政策和同意书要改一处：转发方从“负责人的电脑”改成“阿里云北京的服务器”。数据处理方式变了，建议把应用内同意版本提高到 3，已经同意过的设备会重新确认一次。
- 备案只解决“网站可以在境内服务器上开放”。孩子的个人信息、监护人同意仍按试点手册的同意书执行。
- 试点是邀请制，用访问码限制，不对公众开放。**正式对外之前**，还要确认生成式人工智能服务的备案或登记要求，并做未成年人个人信息保护的合规审查（[产品框架](product-framework.md)第 12 节）。

## 七、现阶段与长期（2026-11-13 补充）

### 地域：北京还是上海

- 之前在上海的只有通话模式实验：AI 实时互动的智能体和函数计算放在华东 2（上海）。阿里云百炼的模型一直在北京，网页语音（主线）每一轮都是“手机 → 小宇记服务器 → 北京的百炼”。
- 服务器放北京，到百炼近；放上海，离华东的家庭近。北京和上海之间一个来回大约差几十毫秒，一轮里有几次这样的来回，总差别在 0.1 秒左右，家庭感觉不出来。
- ICP 备案由**备案人所在省**的管局审核，和服务器在哪个地域无关。以后在阿里云内换服务器、换地域，不用重新备案，最多改一下备案里的 IP。所以这一步不会锁死。
- 建议：试点家庭主要在华东就选上海，否则选北京；拿不准就选北京。

### 个人还是公司

- **试点阶段可以先用个人**：不花钱，不用先注册公司。条件：中国大陆身份证；+86 手机号（接收工信部短信核验）；在阿里云 App 里做人脸核验；备案地址和身份证所在省一致，不一致要有居住证。
- **能不能通过**：这里没有可靠的通过率数据。个人备案的材料一般不复杂，第一次被打回改网站名称或说明很常见，改了再交。主要的不确定在于：个人备案面向个人网站，这里实际是给几个邀请的家庭用的儿童语音服务，**如实写**用途时，初审可能要求改用单位备案。不能为了通过写成个人博客。
- **建议先打阿里云备案客服问清楚**（免费）：“个人主体，网站只给少量受邀家庭测试一款儿童语音陪伴应用，需要访问码，不收费，能不能做个人备案？”客服说不行，再考虑注册个体工商户或公司；或者在那之前先用局域网，找同住或同一 Wi-Fi 的家庭。
- 网站名称要 3 个以上汉字，和本人有关联；“小宇记”这样的品牌名作为个人网站名称可能不被接受，按客服和控制台的指引起名。

### 费用和流程（以页面价格为准）

| 项目 | 费用 | 说明 |
|---|---|---|
| 轻量应用服务器 2 核 2 GB | 开发者社区文章说新用户活动价约 38–68 元/年（限购、条件常变）；不享受活动时，以控制台价格为准 | 备案要求包年包月 3 个月以上，买一年最省事 |
| 域名 | .cn 大约每年几十元，.com 续费大约每年八九十元，首年常有优惠 | 要做域名实名认证 |
| ICP 备案、公安联网备案 | 免费 | |
| HTTPS 证书 | 免费（Let's Encrypt） | |
| 模型和语音 | 试点约 70–130 元（改进计划估算） | 有每日用量上限 |

流程：

1. 阿里云账号个人实名（几分钟）→ 买服务器、买域名（几分钟）→ 域名实名认证（一般 1–3 个工作日）。
2. 域名实名通过后，在备案控制台提交：主体信息、网站信息、证件照片、人脸核验 → 阿里云初审 1–2 个工作日（可能电话联系）→ 工信部短信核验（初审通过后很快收到，按要求回复）→ 管局审核最长约 20 个工作日 → 拿到 ICP 备案号。整个流程约 3–22 个工作日。
3. 备案期间网站不对外开放（部署说明里在拿到备案号后才打开 HTTPS）。
4. 开通后：**网页底部要显示 ICP 备案号**并链接到工信部备案系统；**开通后 30 日内**到全国互联网安全管理服务平台办理公安联网备案，并显示公安备案号。显示备案号需要一处小的页面改动，部署时一起做。

### 长期：从试点到正式上线

能沿用的：

- 阿里云账号、服务器（可以升级配置、换地域、加机器）、域名、这次写好的部署方式（公网模式、Caddy、用量上限）。
- 服务器不保存孩子的数据，扩到多台机器不需要迁移数据。

要重新办或新增的：

- **公司主体**：正式上线、收费或签合作，一般要用公司（或个体工商户）。个人备案通常不能直接改成公司，要注销后以公司重新备案，重新备案期间网站不能访问（1–4 周）。不想中断的话，可以试点用一个便宜的域名，品牌域名留给公司备案。
- **生成式人工智能登记**：调用已备案大模型 API（通义千问）、向公众提供的应用，要到地方网信办登记，并在页面上公示所用模型的名称和备案号。邀请制的小范围试点不对公众开放；正式上线前要办。
- **收费**：在线收费可能还需要增值电信业务经营许可证（ICP 证），以专业意见为准。
- **儿童个人信息**：单独的监护人同意、儿童隐私规则、个人信息保护影响评估；建议做等级保护测评。正式上线前做一次专门的合规审查（产品框架第 12 节）。
- **原生 App**（如果以后做）：还要做 App 备案和应用商店审核。
- **产品和技术**：访问码换成家庭账号；用量上限从内存计数改成共享存储（多台机器时）；监控和告警。
