# 小宇记 UI 与动效规范

> 适用范围：一起聊、家庭设置、成长记录、备份记录及以后新增的网页界面。
> 目标：让低龄孩子和不同教育背景的家长都能一眼找到下一步，同时保持安静、可信、可持续使用。

> 2026-09-09：视觉与信息结构统一参考根目录 `DESIGN.md`；本文件保留动效细则。用户确认的组件设计已接入正式页面，样板仍为独立演示。

## 1. 体验原则

1. **一屏一个主要动作。** 一起聊的主要动作是开始连续对话，不要求每轮按住；成长页的主要动作是回看所选时间的记录。
2. **没有数据就不展示未来模块。** 空摘要、空任务、空时间线和模拟成长结论默认隐藏，不用占位文案制造“已经有内容”的感觉。
3. **分析必须有证据。** 家长先看到日期和简短小发现，原话与来源在记录详情或备份中可查看，不反复铺在首页。
4. **孩子端比成人端更少。** 孩子端不出现设置、诊断、模型状态和成长分析；备用输入只在成人需要时出现。
5. **反馈服务于理解。** 动效只说明按下、正在听、正在想、已经打开或新内容出现，不用来装饰空白区域。

## 2. 信息层级

### 一起聊

- 顶部：会话归属和结束入口。
- 初始：中央小宇作为唯一的大语音按钮；尚无视觉内容时不出现白板。
- 有视觉回应：完整白板，语音入口缩至左下方，不遮挡图画。
- 不显示聊天记录、技术状态、推荐问题列表或多个模式按钮。

### 家庭设置

- 首次使用：孩子昵称、年龄、本机保存同意；此后直接开始对话，不重复设置，不选择时长。
- 孩子资料与家庭成员直接可见；有真实互动后的本次小结与亲子任务收在“本次陪伴”。
- 没有孩子原话或成长证据时，不显示空卡片和空时间线。
- 更多陪伴偏好按需展开；详细原话、导出和整理操作进入独立备份页。

### 成长记录

- 一个时间范围控制简短小发现、领域分布和片段；详细原话移至详情或备份，不重复展示周/月摘要。
- 数据不足时诚实留空，不生成假趋势、分数或同龄排名。

### 桌面与手机

- 大于 900px 使用顶部四入口导航：一起聊、成长记录、家庭设置和备份记录。
- 不大于 900px 使用简洁移动外壳：顶部只保留左侧菜单和居中品牌，首页只保留小宇与一个语音开始动作。
- 移动侧边菜单与桌面导航必须从同一份配置生成，名称、顺序、权限和选中状态保持同步。
- 手机开始会话后，语音按钮占据首屏中心；白板直到有视觉回应才完整展开，不预留空白卡片。
- 不把桌面卡片、开发状态或后端策略压缩后堆进手机首页。

## 3. 控件与状态

- 主要命令使用实心主按钮；次要命令使用浅色按钮；查看类动作用文字按钮。
- 输入框在聚焦时使用清晰边框和柔和焦点环，错误信息出现在对应流程附近。
- 所有可操作元素必须有键盘焦点状态，不能只靠颜色区分。
- 按钮按下缩放到 `0.97`。聆听时仅小宇本体呼吸，运行时由麦克风音量驱动；样板以 `1 → 1.08`、`1600ms` 模拟，静音也不能无限放大。
- 不使用 `transition: all`，只声明实际变化的属性。

## 4. 动效语言

| 用途 | 动效 | 参数 |
|---|---|---|
| 普通按钮按下 | press feedback | `140ms`，`cubic-bezier(0.23, 1, 0.32, 1)`，缩放 `0.97` |
| 输入聚焦 | focus feedback | `140ms`，边框与焦点环渐变 |
| 语音状态 | state transition | `140-220ms`，颜色、阴影、轻微缩放 |
| 菜单状态 | state indicator | 菜单/关闭图标直接切换，不增加装饰性旋转 |
| 手机侧边菜单 | side drawer | `240ms`，同一路径平移，背景遮罩同步变暗，不使用弹跳 |
| 白板绘制 | explanatory motion | 路径约 `900ms`，对象依次出现；只在生成新解释时使用 |

高频导航不做页面滑动或淡入；长期使用时，稳定的位置比“每次都动”更重要。

## 5. 减少动态效果

- 遵循系统 `prefers-reduced-motion`。
- 减少动态效果时取消缩放、路径绘制和弹入；内容直接完整显示。
- 仍保留必要的颜色与状态变化，避免用户失去操作反馈。

## 6. 每次 UI 改动的检查顺序

1. 先问当前页面唯一最重要的动作是什么。
2. 删除没有真实数据支撑的模块和文字。
3. 检查输入、按钮、加载、成功、失败和禁用状态。
4. 只为需要解释状态变化的位置增加动效。
5. 检查时长、缓动、连续操作和减少动态效果。
6. 在桌面及 390px 手机尺寸逐页验证，无横向溢出、遮挡或空内容卡片。
