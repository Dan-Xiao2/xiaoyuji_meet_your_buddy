# 正式页面：回答与语音连接预热

> 2026-11-01 后续：预热方案已调整为“30 秒长连接 + 只在开口时预热”，Agent 在最终转写时、正式页面在说完时的预热已去掉（会抢占回答请求的连接）。见 [模型首句延迟](2026-11-01-llm-first-sentence.md)。

日期：2026-11-01。前置：[TTS 首帧冷连接根因](2026-11-01-tts-first-frame.md)。

## 结论

正式（半双工）页面存在同样的冷连接问题。服务端在孩子开口、说完这两个时刻各并发预热两条连接后，真实 HTTP/WebSocket 链路中：短回答从平均 1628ms 降到 1079ms，TTS 首个音频从平均 1448ms 降到 736ms，**每轮快约 1.26 秒**（各 3 次，系统合成中文）。

## 为什么要并发两条

正式页面的顺序是：短回答 `/api/tutor/quick` 返回后，浏览器几乎同时发出 `/api/speech/stream` 和后台补全 `/api/tutor`，两者争用短回答刚释放的连接，争不到的一方就要冷启动。

先后发两次预热无效：第二次只会复用第一次留下的连接，池里仍然只有一条热连接。最初一版就是这样，短回答变快了（约 2.0s 降到 0.97s），但 TTS 没变（1.3–2.4s），新建连接数统计证实了这一点。改成每次并发两个请求后，TTS 也降下来了。

LiveKit 实验 Agent 使用同一模块，现在同样一次预热两条连接。上一轮观察到“模型首句没改善”，可能的原因之一是只有一条热连接、被 TTS 拿走了，但没有在 Agent 内统计连接数加以证实。改后只跑了 1 次闭环，当时机器负载约 7–17，样本不可靠：模型首句 1328ms，看不出改善；TTS 首帧 663ms 仍然有效。

## 实测（真实正式服务端，合成中文 1.8 秒，WebSocket 实时 ASR → quick → 同时 TTS 与补全；每轮前空闲 6 秒）

| | 不预热 | 预热（并发两条） |
|---|---|---|
| quick 回答（ms） | 1708 / 1461 / 1714 | 960 / 1003 / 1273 |
| TTS 首个音频（ms） | 1304 / 1255 / 1784 | 706 / 888 / 614 |

同进程模拟（直接调用服务端函数）结果一致：quick 1662 → 1046ms，TTS 1266 → 814ms。6 次转写均完整。

## 改动

- `server/providerWarmup.mjs`：默认 `sockets: 2`，并发发出；`PROVIDER_WARM_CONNECTIONS=false` 关闭（实验页原有的 `VOICE_LAB_WARM_CONNECTIONS=false` 仍然有效）。
- `server/realtimeAsr.mjs`：新增 `onSpeechActivity` 钩子，在一次发言建立连接时（浏览器本地已检测到有声）和收到 `finish` 时调用；钩子抛错不影响识别。
- `server/server.mjs`：用 `createProviderWarmup()` 接入。
- 测试：`provider-warmup.test.mjs` 增加并发和关闭开关断言；`realtime-asr.test.mjs` 增加钩子触发时机及抛错隔离。

批量 ASR 回退路径（`/api/transcribe`）没有接入：它本身就用 fetch 访问同一主机，相当于自带预热，而且只是回退路径。

## 验证

- `npm run check` 退出 0（418 项 Node 测试加 smoke）。
- `npm run check:browser`：除 `exploration-pipeline-browser.mjs` 外全部通过。该用例在第 86 行等待 30 秒超时，**改动前的提交上同样失败**（暂存改动后单独运行，失败位置相同）。它拦截全部 `/api/**` 请求，不经过服务端 ASR 和预热，与本次改动无关。10 月 28 日的记录已提到“探索流程超时尚未定位”。运行时机器负载约 11–14。
- LiveKit 真实闭环：第 1 次 Agent 派发失败（no response from servers，负载 17），等负载降下来后第 2 次通过。

## 限制

- 每轮多 4 次模型列表请求（2 次时刻 × 2 条）。按目前所知不计费，但会占用接口频率额度，供应商限流规则未查。
- 只在本机网络、合成语音、同一句话上验证，每组 3 个样本。境内服务器离供应商更近，收益会变小，需要重新测量。
- 一句话超过约 3 秒时，开口时的预热可能在短回答请求前过期，说完时那次仍然有效。

## 费用

模拟和端到端各 6 轮（每轮短回答、补全、TTS 各一次，外加实时 ASR），加 2 次 LiveKit 闭环，估算低于 0.2 元，未查询账单。
