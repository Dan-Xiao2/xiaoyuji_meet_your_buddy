# 探索对话流程：实施与未完成项

日期：2026-10-19。范围：文字/语音转写的分享发现 → 提问 → 纠正 → 换题 → 自然结束。不是强制孩子按五步聊天；没有接入照片、修改 API 账号或扩大采集。

## 本轮改动

| 问题 | 改动 | 边界 |
|---|---|---|
| 提示词、知识卡容易带向任务 | quick/complete 共用探索原则，明确当前问题优先、无需每轮追问或画图；标明只有文本、没有照片 | 提示词不保证模型每次遵守，真实结果见下文 |
| 旧太阳上下文穿过新对象 | 最近孩子话题成为上下文边界；明确纠正/换题不沿用旧太阳事实 | 有界规则，不是通用语义理解器 |
| “一座积木塔”误入算数 | 数量必须邻接“块/个积木”等数量表达，不再凭任意数字触发 | 保留既有明确数量互动；其他分享误判仍需扩样 |
| 明确换题仍先走旧图路由 | 取消旧绘图请求，普通新话题直接对话；明确的新绘图请求仍可分流 | 没有穷举所有自然语言换题表达 |
| 告别仍继续收音 | 安全分流后，本地识别完整告别句；结束会话、取消在途请求、停止收音，至多播一次告别，不自动再听 | 不把“别画了”、引用“再见”、危险求助或问题误当告别 |
| 后台晚到覆盖对话 | 复用既有回合/会话取消与有限提交，增加告别后 ASR/补全晚到检查 | 没有重写控制器或存储 |

实现位置：`src/services/conversationIntent.js`、`src/whiteboard/visualPlan.js`、`server/scienceContext.mjs`、`server/qwenTutor.mjs`、`server/knowledgeCardSelector.mjs`、`src/app.js`。

### 发现的质量缺口

1. 第二批分享后连续两次主动提议画叶子；纠正为纸后仍问是否虫咬。旧规则只排除“虫子吃的”，漏掉了“虫子咬的”，说明关键词通过不等于真正听懂。
2. 最后一批不再提议画画、没有再沿用虫子，但首句仍是“哇，有洞的叶子真特别”，纠正后仍问“纸上有洞是因为被剪刀剪开或者笔戳破了吗？”；尚未做到只确认纠正、不追加猜测和追问。
3. 影子回答提到挡光，但没有充分解释移动关系；太阳“大电池”的比喻也值得进一步校核。不能因主题词匹配宣布科普准确。
4. 已收紧固定样例，捕捉主动画图、固定“哇”开场、纠正后虫子残留与追问。用现有最后一批输出离线重评分，仅1/3通过；没有为更好分数追加付费调用。

## 下一批与开放项

- 先解决真实样例里的纠正后推测、固定赞美及诱导式提问。不要硬编码“叶子/纸”的标准答案；扩大未见场景做对照，任何进一步付费评测另行确认预算。
- 首轮冷启动/网络超时原因未分解；不能用文本约1秒推断语音首声约1秒。ASR、真实幼儿发音、TTS播放及设备路由仍需本人本机验证。
- 本轮真实请求仅覆盖快速回答。后台证据提取只做模拟回归，未完成真实多轮证据质量审阅。
- 告别/换题规则是有限表达集；含糊表达、混合命令、纠正后的长期记忆需要独立扩样。
- 成长候选自动保存与显式选择的既有差距未修改；照片输入、家庭价值、专业复核、付费转化仍开放。

结论：流程控制和回归已推进，模型回答质量仍是部分实现；不将20次小样本作为稳定性、儿童安全或产品价值证明。
