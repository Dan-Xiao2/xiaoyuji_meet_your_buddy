# LiveKit真实服务联调记录

日期：2026-11-01。结论：**真实接口及一次本机媒体闭环接通；识别、延迟和稳定性尚未达标。** 这不是模型级原生Full-Duplex验收，不是儿童体验或iPhone后台验收。

用户授权总预算人民币10元，只使用系统合成语音。密钥由用户在本机配置，未进入报告、补丁或聊天。没有修改用户的真实配置、正式网页入口或家庭档案。

## 实际完成

1. 一次独立真实服务探测：系统Tingting合成“天空为什么是蓝色的？” → Qwen实时ASR → 真实文本模型 → 真实流式TTS。没有使用备用回答。
2. 一次完整闭环成功：合成麦克风 → 本机LiveKit WebRTC → Node AgentSession → Qwen ASR/LLM/TTS → 浏览器接收非零音频。第二次重叠语音打断当前播放，结束会话后麦克风轨道结束、音频元素移除，观察800ms没有第二条模型回答。此窗口不能证明任何长时间迟到事件都不存在。
3. 完整链路首次失败：Agent未成功派发，客户端在20秒就绪超时后清理；测试最终等待45秒失败。保留失败报告。未改业务代码重试后通过，证明连通性，**不证明偶发失败已修复**。
4. 新增可显式选择真实服务的浏览器检查。默认仍为免费合成提供器；真实检查必须显式给出合成中文WAV，避免默认英文样本被误作中文验收。没有自动付费重试循环。
5. 本轮`npm run check`退出0：395项Node测试及独立smoke检查通过；其中LiveKit定向测试10项。默认免费WebRTC五组检查通过，含语音重叠打断、第二轮回应、停止和连接中取消。未将本轮结果写成重新跑过上批400项及13组发布流程。

## 实测结果及解释

以下每项只有一次成功样本，不是P50/P95。服务调用实际从这台Mac发往已配置的北京域名，**没有大陆家庭网络测量**。

| 环节 | 观测 | 能证明什么 |
|---|---|---|
| 独立ASR | 合成语音1.803秒；转写“天空为什么是蓝色的？”；输入开始至结果3079ms | 此样本真实接口可用，单样本完整识别 |
| 独立LLM | modelUsed=true；1891输入Token、29输出Token | 使用真实模型，未走本地备用 |
| 独立TTS | 480000字节24kHz单声道PCM，约10秒；请求至首块677ms | 返回实际音频；不证明自然度或端到端延迟 |
| WebRTC转写 | 输入开始至转写2933ms；只识别“为什么是蓝色的？” | **漏掉开头“天空”**，语义质量失败 |
| WebRTC回答 | 输入开始至生成5467ms | 完整短回答后才交给TTS；仍非token流式 |
| WebRTC音频 | 输入开始至收到非零音频6463ms | 远端音频真实到达，不代表人耳听到、内容对齐或儿童已听完 |
| 重叠打断 | 重叠合成语音开始至观测静音2704ms | 功能发生，但响应太慢；不是SDK通知后尾音指标 |

输入开始计时包含1.803秒发言，不能直接与“发言结束至首音”混用。简单相减约4.66秒也只是假定完整采集情况下的近似；本轮没有精确终点和阶段时钟，不把它写成正式延迟指标。打断静音检查为收到SDK打断事件后能量低于0.001，尚未检验长窗口残音，也不是200次P95验收。

## 暴露的问题与下一步顺序

| 问题 | 已有证据 | 下一步最小改动与验收 |
|---|---|---|
| 偶发Agent接入失败 | 首轮no servers available；重试通过 | 记录派发、进程预热、订阅音轨时间。不要仅放宽超时；连续合成接入检查无失败后再扩大 |
| 开头漏词 | 直接探测完整，WebRTC路径漏“天空” | 增加采集首帧、Agent收到首帧、ASR session.updated/首个append的时间与样本数。比较立即发言/已有连续收音后的发言；确认丢帧位置后修复就绪或缓冲合同，避免盲加固定等待 |
| 回答臆测对象 | 缺主语时模型说“你是说天上的云吗” | 保留问题歧义的测试，不把缺失对象自行当作云；先修识别，再用上下文不明时的有限澄清检查。未在本轮改提示词或声称已解决 |
| 播放响应慢 | 单样本6.463秒，LLM完整回复后再TTS | 分开记录断句/转写/LLM首片与完成/TTS首块/浏览器首音；隔离主机负载后再比较。若模型等待是主要部分，再做带短句安全检查的流式回答 |
| 打断慢、调度停顿 | 单样本2.704秒；CPU与事件循环告警 | 区分输入检测、SDK取消、TTS请求取消、接收端残音；先在独立空闲进程测量，再调400ms VAD阈值。不能将所有延迟归给供应商或网络 |

日志中出现CPU高负载、process not scheduled、event loop blocked及连接关闭时DTLS告警。它们与当前异常共现，但没有证明漏词或延迟的因果关系。没有通过杀用户程序、放宽断言、强行接收过载任务来制造成功。

建议下一批只做上述阶段测量和首词保护，不全面重构。随后在大陆网络成人样本上形成分布，才安排儿童停顿/附和、回声和误打断测试。iPhone仍需原生音频层及锁屏/来电/蓝牙验证；当前网页隐藏即停止。
