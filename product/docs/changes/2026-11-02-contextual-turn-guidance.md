# 对话接话优化第二批：消除短答与拒绝指引冲突

2026-11-02。基于第一批代码核查和可复现指令冲突，作最小运行时修改。真实模型基线尚未采集；这是生成指引修正，不是已证实的自然度提升。

## 修改

- `server/turnGuidance.mjs`：明确的完整第一人称拒绝（包括“不知道，我现在不想说”）优先使用拒绝/说完指引，不再要求分享展开。仅识别有限完整表达，不搜索任意叙述中的“不想”；混合句主动提问仍按提问处理，故事角色拒绝不当成孩子停止指令。
- “没有／没有了／没了／没事了／没什么了”改为有歧义的短答，不直接断定分享结束。指引要求模型结合已传入的上一轮区分物体不存在、回答问题或说完；若确实说完，仍简短接住。不是新增上下文语义分类器，实际理解仍依赖模型。
- “嗯／哦”等不再断言没有新内容；要求区分对问题/建议的回答与听解释的附和。有帮助时保留相关细节。
- “不知道”区分事实问题与暂时说不清感受/经历，不指定感受、不考问。
- 感受回应不再必须追问；上轮包含问号时，所有类别均限制本轮以问题结尾，不再豁免feeling。问号只是有限启发式，无法识别所有无问号问句或引用中的问号。
- 分享、问题不强制添加新细节或现实任务；保留有帮助的话头。纠正/拒绝优先于分享展开。
- `server/qwenTutor.mjs`：quick/stream共用话头指令移除对“嗯／不知道／没有了”的绝对解释；纠正后采用新信息，只在关键指代不清时澄清，不默认再问一句。可选turnGuidance关闭时，共享话头也使用上下文原则。

只修改现有生成指引和有限分类，不新增网络调用、状态、API、模型或持久化格式。普通拒绝不会关闭麦克风；媒体结束仍由原有控制逻辑负责。安全分流及本地提前返回路径不变。
