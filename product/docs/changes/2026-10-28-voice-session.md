# 小宇记主入口拆分：第 1 / 3 批

日期：2026-10-28。目标：移出语音生命周期协调，保持现有产品入口、ASR/TTS 服务和半双工方式。

## 本批落地

新增 `src/features/voice/voiceSession.js`，集中管理收音、转写处理、播报准备、播放、暂停及自动续听。每次采集和播报使用独立代次，并校验会话身份；被取消或被替换的旧回调不能提交转写、推进白板或重新打开麦克风。每段播报的结束/失败只能处理一次。

`src/app.js` 通过少量适配函数连接按钮、状态文案、白板和语音控制器。入口保留内容安全检查、选择要播的回复、对话提交和档案操作；底层 `voiceService.js` 继续负责设备与现有云服务。本批主入口缩短约 180 行，没有增加第三方依赖。

## 责任与接口

| 模块 | 责任 |
|---|---|
| app.js | 组装依赖、页面交互、安全发布、业务结果提交 |
| voiceSession.js | beginInput / finishInput、prepareTurn、pause / resume、playReply、acknowledgeEnd；维护媒体状态和续听计时器 |
| voiceService.js | 麦克风采集、识别、合成播放和既有回退 |
| whiteboard.js | 按语音开始呈现分段画面，失败时呈现完整画面 |

控制器只读取当前会话、页面是否允许收音、主回复是否等待等必要信息；不读写 DOM、档案或完整业务状态。后台证据补全不阻挡正常续听。

## 验收

新增 9 项控制器测试：单次转写提交；暂停及新输入拒绝旧回调；续听时重查页面/会话/等待状态；手动结束收音接收一次最终结果；播放失败暂停续听并允许重播；分段画面与声音开始对齐且忽略重复结束；静音白板展示；结束后的告别不重开麦克风。

集成浏览器检查发现原生计时器以对象方法调用导致 Illegal invocation，已改为包装调用；保留现有浏览器异常断言验证该问题。

最终 `npm run check:release` 退出 0：314 项 Node 测试（语音相关 86 项，含新增 9 项）、知识校验、架构校验、smoke 和 8 组模拟浏览器流程全部通过。真实儿童语音、设备尾音与模型回答质量不在该模拟验收范围内。

架构图由原 JSON 源更新生成：9/9 产物检查通过，1440×900、1600×1000、1920×1080、2048×1320 自动浏览器检查通过。实际查看 1440 浅色和 2048 深色截图，节点、连线和说明卡无可见遮挡或溢出。自动回执中的 visualReview: pending 是工具固定字段，人工图像复核独立记录于此。
