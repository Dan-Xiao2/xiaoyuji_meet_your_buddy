# 前端边界第一批：本轮证据与保留画面分离

日期：2026-10-30。基于现有未提交的 A/B/C 改动继续实施，不回退既有工作。

## 范围与实现

本批先修正记录含义，再建立能验证真实请求顺序的测试；没有把整个入口搬到一个新文件，也没有关闭绘图功能。

- 新增 `src/features/growth/growthTurnContext.js`，从本轮候选及接收后的状态捕获有限的领域、标题、主题和画面上下文。仅本轮视觉计划或明确活动关联到、且实际接受的画面能进入上下文；保留屏幕画面本身不构成新证据。
- `app.js` 在普通对话 pending 接受后捕获上下文，quick 接受后才保存记录；后台补全复用这份上下文和已保存片段身份。精确白板在受限合并后捕获当前结果。原有 session、revision、取消和家长修订保护保持有效。
- 普通聊天不继承旧画面的领域、标题、主题或快照；无明确活动的普通聊天暂沿用 language 分组，不新增语义分类器。无附图使用现有可空字段 null，生成图片仍不复制到成长记录。
- 无变化、等待规划、澄清及控制性绘图请求仍不创造新的成长片段。这里的画面是互动辅助材料，不是孩子在现实中完成活动的证明。
- `openDrawingClient.js` 校验 route 的模式及必要字段；空对象、未知模式、缺失回复或图片操作参数沿用失败澄清路径，不再默认为需要规划。
- 没有改变 API 路径或档案格式，没有新增数据上传，也没有批量修正已有历史误关联。对旧图的自然语言追问暂不自动附图，待有可靠关联规则后另行设计。

## 测试修复

- 绘图脚本显式模拟聊天路由、图片不可用及格式错误；未声明的业务请求让测试失败。保留原图与正确保存证据分别断言，不再把聊天换题等同于必须清空白板。
- 白板脚本的 quick 返回 used:true，门控补全请求；先验证快速记录，再释放携带无关月亮画面的补全，验证同一记录修订、画面不被替换、证据仍无旧图。
- 明确将 MP3 预取模拟为不可用，播放使用合成静音 PCM；重播按钮实际仅重播视觉步骤，测试等待第一帧发生，再确认取消后第二帧不能推进。没有将视觉重播误当成语音请求。
- 两组原扩展脚本纳入关键浏览器回归；新增成长上下文和路由合同 Node 测试纳入标准检查。
- 统一停止测试的路由模拟从不存在的 plan/generate 改为接口约定的 precise/create；继续要求目标请求真正开始，再取消并检查迟到结果。没有放宽产品校验来适应错误模拟。

## 失败复现与校正

改产品代码前，纠正测试自身的前提后复现：房子后问太阳被记为 art；积木后问恐龙被记为 math。日志为 `work/frontend-boundary-1/logs/before-browser-corrected.log`（位于当前工作会话目录）。路由单元测试也在改前因 null 响应缺乏校验失败。

初次探测把经过档案规范化的画面与运行画面直接比较，并等待视觉重播不存在的语音请求；这两项属于测试前提错误，已经纠正。第一次修复后测试仍按旧预期读取 blank.type，而新代码用已有 null 表达无附图；已改为精确断言 null。以上失败日志保留，没有计入通过结果。

首次完整发布回归在 1440×850 的语音按钮首屏断言失败。使用只替换 JavaScript、保持正确 CSS 加载的改前/当前对照，按钮底部都为 928.5px：画区仍留 110px 底部空间，按钮已处于独立下方行。仅在正式孩子白板样式中将此留白改为16px；不隐藏溢出、不缩小按钮、不删除首屏断言。390px旧对照没有布局失败与这次1440px发现并不矛盾。

第二次完整检查的前12组浏览器流程通过，末组停止检查的 plan/image 场景没有启动目标请求。确认是上述旧路由模拟被新合同校验拒绝，修正模拟后重新运行完整检查；没有把第二次退出码1记录为通过。
