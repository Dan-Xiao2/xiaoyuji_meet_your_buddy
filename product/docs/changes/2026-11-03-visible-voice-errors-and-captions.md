# 聊天页：看得见的出错原因和大人字幕

日期：2026-11-03。来自界面结构审查。

## 问题

- 麦克风打不开时（没有权限、找不到设备、被别的应用占用），聊天页只显示"再试一次"。真正的原因，比如"麦克风未获允许，请检查浏览器或系统的麦克风权限"，只写在读屏软件才会读的隐藏文字里，大人在屏幕上看不到。
- 识别出的文字和小宇的回答也只在隐藏区域里。试用时家长说"小宇听错了"，页面上没有地方能核对她听成了什么。

## 做法

- **出错提示**：聊天页小宇按钮下方新增 `#voiceNotice`。听的过程中出错时，会把原因用浅红底的小字显示出来，下次点小宇开始听时自动清掉。读屏软件原来就能从 `#voiceTranscript` 读到同样的内容，所以这个提示设为 `aria-hidden`，避免念两遍。
- **大人字幕**：
  - 家庭设置 → 麦克风里新增开关"聊天时显示字幕（给大人看：小宇听到了什么、回答了什么）"，默认关闭，这样孩子看到的仍然只有小宇一个画面。
  - 打开后，聊天页会显示最近一句"听到"（孩子说的话）和最近一句"小宇"（她的回答）。
  - 开关只保存在这台设备上（`xiaoyuji-captions-v1`），"清空本地数据"时会一起清掉。
  - 字幕只在页面上显示，不写进任何记录。

## 验证

- 内置浏览器手机宽度：在麦克风被禁用的环境下点小宇，屏幕上显示"麦克风未获允许，请检查浏览器或系统的麦克风权限。"
- `tests/barge-in-browser.mjs`：字幕默认隐藏；打开后，问一句话，屏幕上显示孩子的原话和小宇的回答；开关的选择被保存。
- `tests/microphone-input.test.mjs`：字幕开关默认关闭，开和关的设置都能保存。
- `npm run check` 和 17 个关键浏览器流程全部通过。

## 未做

- 字幕要等回答完整生成、保存成消息后才更新，逐句播放时不会一句一句跟着出。
- 界面审查里提到的问题都已处理，见下面第二、三组。

## 第二组：首次使用与保存开关

- **首次打开**：在"请大人先设置"下方加了一个"去设置"按钮。原来只有小宇的图片能点，但看不出来能点。
- **提示间距**：没勾选同意时出现的提示，原来贴着"开始聊天"按钮，现在和按钮之间留出了间距。
- **保存开关**：原来家长在资料里关掉"保存孩子的成长记录"后，就再也开始不了聊天；而这个开关本身也不决定存不存记录。现在按用户的选择处理：
  - 首次使用仍然必须勾选同意，和产品框架一致；
  - 之后关掉开关，仍然可以聊天，只是不再写入成长片段、学习事件、家长观察和会话记录（`src/app/applicationPersistence.js`）；孩子资料照常保存，已有的记录不删除；
  - 开关下方加了一行说明。
  - 旧数据里如果没有这个字段，按"保存"处理。
- **还没做**：本次聊天的对话内容仍会留在这台设备的页面状态里，用来保证刷新后能接着聊。下次开始聊天时会被新会话替换，但不会立刻删除。
- **测试**：
  - `tests/application-persistence.test.mjs`：关闭保存后，只保存孩子资料；重新打开后，成长片段恢复保存。
  - `tests/production-design-browser.mjs`：已关闭保存的家庭，从首页能直接开始聊天；数据库里只有孩子资料，没有会话记录和成长片段。首次使用仍然必须同意。

## 第三组：家庭设置与菜单

按 `DESIGN.md` 和 `docs/ui-motion-guidelines.md` 的结构调整：孩子资料和家庭成员直接显示，本次小结放在"本次陪伴"里。没有另起新方向。

- **聊天面板的标题**：原来聊天进行中也显示"先认识一下孩子"。现在第一次设置前显示"先认识一下孩子"，聊天中显示"正在聊天"，和按钮之间也留出了间距。
- **设备与测试**："麦克风"（改名为"麦克风与语音"）和"测试数据"移到页面最下方，放在"设备与测试"标题下。这样它们不再和孩子资料、成长记录混在一起（`AGENTS.md`：家长端不混入内部工具）。
- **手机菜单顶部**：设计样式隐藏了头像图片，但网格仍按"头像 48px | 文字 | 关闭按钮"三列排，文字被挤进 48px 宽的那一列，"小宇记"断成两行，家庭信息也被截断。现在改为两列。关闭按钮也从 40px 加大到 44px，达到图标点按区域的最小要求。
- **成长记录页的按钮**：聊天进行中，空白成长页的按钮改为"回到聊天"，和家庭设置页的说法一致。
- **验证**：在内置浏览器里按手机宽度看过菜单、聊天中的家庭设置和页面底部的"设备与测试"。`tests/archive-operations.test.mjs` 新增按钮文字随聊天状态变化的检查。`npm run check`、17 个关键浏览器流程和麦克风设置浏览器测试全部通过。

## 按新规则精简文字

`AGENTS.md` 新增一条规则：避免不必要的次级标签和说明，让布局本身说明结构；只有布局表达不了的后果或限制，才加一句短说明。按这条规则做了以下精简：

- **字幕**
  - 开关文字改为"显示字幕"。
  - 去掉"听到""小宇"两个标签：孩子的话用浅色字，左边加一条细竖线；小宇的回答用正文深色。
- **删掉的装饰性小标签**："一起玩一会儿""最近的小变化""慢慢长大"，以及"你看到的，比对错更重要""说话人由你选择"（这一条原本就隐藏）、"（可不填）""（可选，4位数字）"。
- **缩短的说明**（都是布局看不出的后果，所以保留，只改短）：
  - 保存开关："关闭后仍可聊天，不再保存新记录。"
  - 测试录音："只在本机试听，不上传。"
  - 测试数据："只含耗时和失败代码，不含录音和文字。"
  - 聊天状态："已聊 N 轮"。
  - 备份页："共 N 条"。
- **保留的**："保存在这台设备"（说明数据只存在本机），以及"1 个孩子 · 最多 6 位家长"（说明人数上限）。
- **验证**：在手机宽度下看过字幕的排版；`npm run check` 和 17 个关键浏览器流程全部通过。
