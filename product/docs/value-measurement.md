# 价值验证测量：每次聊天的结果和家长的回答（2026-11-13）

> 对应 [改进计划](improvement-plan-2026-11.md) 阶段 3。目的：家庭试点时，用数字回答北极星的两层问题。孩子当下：愿不愿意说、纠正后有没有被接住、是怎么结束的。家庭长期：会不会再来、家长觉得有没有用、会不会收藏和修改片段。只在这台设备上记录，只记数字和类别，不记原话和录音。

## 记什么

每次聊天结束时，在这次聊天的记录上写一份“结果”。

| 字段 | 含义 | 怎么得到 |
|---|---|---|
| `entry` | 从哪里开始的：`child-home` 孩子页面上的小宇，`parent` 家长区 | 开始聊天时记下 |
| `mode` | `web` 网页语音、`call` 通话模式、`mixed` 中途换过 | 每轮记下 |
| `childTurns` / `adultTurns` | 孩子说了几句、家长说了几句 | 按聊天时选的“当前说话人”区分；“家长代说”就是 `adultTurns` 大于 0 |
| `corrections` | 孩子纠正了几次 | 一句话以“不是 / 不对 / 错了 / 才不是 / 你听错了 / 我说的是……”开头（不含“不是很……”“不是吗”），`isCorrection` |
| `correctionsAdopted` / `correctionsRepeated` | 纠正后，孩子下一句是否又在纠正 | 下一句不是纠正，算“接住了”；又是纠正，算“没接住”。最后一次纠正后如果没有下一句，就两边都不算 |
| `interruptions` | 孩子打断小宇几次 | 网页语音确认打断时，或通话模式里小宇的话被打断时 |
| `failures` | 出问题几次 | 麦克风或识别出错、小宇的声音放不出来、通话断开 |
| `minutes` | 从开始到最后一次说话的分钟数 | 不算最后离开的空闲时间 |
| `end` | 怎么结束的 | `farewell` 孩子说再见；`adult` 有人按了“结束”；`left` 没结束就离开了；`technical` 最后发生的是出错，然后结束或离开 |
| `feedback.useful` | 家长：对孩子有用吗（有用 / 一般 / 没用） | 聊天结束后家庭设置页顶部的卡片，一下点选，可以不答 |
| `feedback.initiator` | 家长：是谁想聊的（孩子自己 / 家长提议） | 同一张卡片 |

导出时，每次聊天一行，另加三项从已有记录算出来的数字：

- `dayIndex`、`daysSincePrevious`：第几天（从第一次记录的聊天算起），以及距上一次聊天隔了几天（再次使用）。导出里没有日期。
- `starredMoments`、`editedMoments`：这次聊天的成长片段后来被收藏、被家长修改了几条（包括之后几天才收藏的）。

## “离开”怎么算

聊天没有按“结束”，孩子走开了，页面一直停在聊天状态。超过 30 分钟没人说话，下次点小宇（或在家长区点“回到聊天”）时，旧聊天记为 `left`，并直接开始一次新聊天。这样隔天回来算一次新的聊天，“再次使用”才数得准。30 分钟以内回来，还是接着原来的聊天。

## 在哪里看

- **家长回答**：聊天结束后，家庭设置页顶部出现“刚才这次聊天”：“对孩子有用吗？”“是谁想聊的？”，以及“收藏片段”（打开成长记录）和“跳过”。不显示次数，不提醒，不出现在孩子的页面上；两项都答了或点了跳过，就不再出现，下次聊天结束后换成新的一张。
- **最近几次聊天**：家庭设置 → 设备与测试 → 测试数据，列出最近 5 次，例如“11月13日 · 孩子说了 4 句 · 纠正 1 次，1 次下一句没再纠正 · 孩子说了再见 · 有用”。
- **导出**：同一处的“导出测试数据”，文件 `schema: 2`，`sessions` 里每次聊天一行。

## 隐私

- 只有上表里的数字和类别（允许列表在 `sessionOutcome.js` 的 `normalizeOutcome` 和 `pilotLog.js` 的 `SESSION_NUMBERS` / `SESSION_CODES`）；不含原话、录音、姓名、日期。
- 跟着“保存孩子的成长记录”开关走：关掉后不再写；记在聊天记录上，所以会随备份导出、恢复，随“清空本地数据”一起删除。
- 隐私政策第 1 节已改为列出“使用和测试数据”。这是只在本机的新类别，当前的同意版本（2）没有提高；给新家庭试点时他们第一次同意就会看到新文字。通话模式开放前要一起提高同意版本（见 [voice-status.md](voice-status.md)）。

## 局限

- “纠正被接住”是近似：只看孩子下一句有没有又在纠正，不看小宇说了什么。试点时要和观察记录对照。
- 纠正只认句首的几种说法；“我要的是小猫”这类不会被认出来。
- 发起方式靠家长回答；`entry` 只说明是在哪个页面点的，不代表是谁的主意。
- 家长不回答很正常，不能把“没回答”当成“没用”。
- 30 分钟是估计值，试点后再看是否合适。
- 没有真实家庭数据前，这些数字只说明测量能用，不说明产品有价值。
