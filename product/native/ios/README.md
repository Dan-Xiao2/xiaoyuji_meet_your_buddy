# 小宇外放测试（iOS 原生技术验证）

> 对应 [docs/native-app.md](../../docs/native-app.md) 第 1 步：开着麦克风、用 iPhone 外放播放小宇的声音时，会不会炸音、音量够不够、能不能听到孩子插话、会不会被小宇自己的声音打断。
>
> 这个 App 不连网、不录音、不保存任何声音：麦克风只用来算声音大小。小宇的声音是 App 里自带的一段录音（`xiaoyu-sample.wav`，用小宇记同一个音色合成的 5 句话，41 秒，循环播放）。

## 三种方式

| 方式 | 做法 | 预期 |
|---|---|---|
| A 通话级回声消除 | 音频会话设为语音通话模式，打开系统回声消除（FaceTime 这类通话用的处理） | 希望：不炸音、外放清楚、能听到插话、不被自己打断 |
| B 回声消除 + 普通模式 | 同样打开系统回声消除，会话用普通模式 | 和 A 对比音量 |
| C 不消除（对比） | 不做回声消除 | 大概率会被小宇自己的声音触发，用来对照 |

## 1. 装 Xcode（你来做）

1. 在 Mac 的 App Store 搜索 Xcode 并安装。安装和 iOS 组件一共要几十 GB，这台 Mac 现在有约 40 GB 空余。
2. 打开一次 Xcode，同意许可。提示安装 iOS 组件时选安装（也可以在 Xcode → Settings → Components 里装）。
3. 在终端运行一次（要输入电脑密码）：

```bash
sudo xcode-select -s /Applications/Xcode.app
```

装好后告诉我。我会先在电脑上编译一遍，有错误先改好，你再接手机。（2026-11-13：已用 Xcode 27.2 编译通过，模拟器版和真机版都没有错误。）

## 2. 装到 iPhone（你来做，约 10 分钟）

1. 打开项目：

```bash
open native/ios/XiaoyuAudioCheck/XiaoyuAudioCheck.xcodeproj
```

2. Xcode → Settings → Accounts，加上你的 Apple ID（免费的就行）。
3. 左侧选项目 → Targets 里的 XiaoyuAudioCheck → Signing & Capabilities → Team 选你的 Apple ID（Personal Team）。提示 Bundle Identifier 被占用时，把最后一段 `t4r8q` 改成别的字母。
4. 用数据线连上 iPhone，手机上点“信任此电脑”。Xcode 顶部的运行目标选你的 iPhone，按 ⌘R 运行。
5. 第一次运行时：
   - iPhone 会要求打开开发者模式：设置 → 隐私与安全性 → 开发者模式 → 打开，手机重启后确认。
   - 再运行一次。如果手机提示“不受信任的开发者”：设置 → 通用 → VPN 与设备管理 → 开发者 App → 信任 “Apple Development: 你的 Apple ID”。这是 Xcode 用你自己的 Apple ID 生成的证书，不是别人的。
6. 免费 Apple ID 装的 App 7 天后会失效，测完可以长按图标删除。

## 3. 测试（每种方式约 3 分钟）

准备：不戴耳机，安静的房间，手机放桌上，音量调到七成以上。

每种方式按顺序：

1. 选方式，点 **开始**。看“声音从哪里出来”是不是 **扬声器（外放）**。
2. **安静测试**：打开“安静测试”，点 **小宇说话**，1 分钟内不要说话。看“安静时误触发”的次数。
3. 关掉“安静测试”，点 **小宇说话**。小宇说话时，在离手机约 1 米的地方用平常音量插话，共 10 次；小宇停下后再点“小宇说话”继续。看“插话被听到”的次数。
4. 自己判断两件事：有没有炸音、咔哒声或电流声；不贴着手机能不能听清小宇。
5. 点 **复制结果**，粘贴到对话里，再加上第 4 步的两个判断。
6. 点 **停止**，换下一种方式。

如果 A 在安静时也会误触发，把“插话门槛”往右调高几 dB 再试；如果插话总是听不到，往左调低。门槛会写进复制的结果里。

## 通过标准

A 或 B 有一种做到：外放正常音量下没有炸音；不用贴着手机也听得清；10 次插话至少听到 8 次；安静 1 分钟误触发不超过 1 次。

通过后进入第 2 步原型：网页界面放进 App，录音、播放和打断换成原生，接小宇记现有的识别和朗读。没通过，就把结果记下来，原生 App 暂停。

## 结果（2026-11-13）

- A（通话级回声消除）iPhone 外放真机：不炸音；插话 10/10 被听到；安静 64 秒误触发 0 次；安静时麦克风最高 -56 dB、插话时 -18 dB（门槛 -38 dB），系统音量 45%。
- 待测：不贴着手机能否听清；音量八成左右是否仍不炸；B、C。

## 文件

- `XiaoyuAudioCheck/AudioCheck.swift`：音频会话、回声消除开关、播放和插话判断。
- `XiaoyuAudioCheck/ContentView.swift`：界面。
- `XiaoyuAudioCheck/xiaoyu-sample.wav`：小宇的测试录音。
- `XiaoyuAudioCheck.xcodeproj`：项目文件（Xcode 16 及以上；文件夹里的文件会自动加入项目）。
